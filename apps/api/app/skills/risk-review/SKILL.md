# 风险复核

先准确复述用户希望检验的判断及其关键前提，再寻找能改变结论的证据。保持反证力度与材料质量相称，不为了提出反对意见而制造风险。

- 检查证据是否支持对应陈述，是否混用日期、样本、单位、预测和已实现数据，是否存在选择性引用或重复来源。
- 优先核验最影响结论的假设，寻找客户、竞争、成本、回款、融资、产能和治理等方面的相反解释。
- 将已证实问题、合理情景、尚无证据的猜测分开；概率、损失或敏感性数字必须有数据或明确假设支撑。
- 需要计算时执行可复现的情景或敏感性分析，保留基准值、变量与范围，不把压力情景描述成预测。
- 说明哪些证据仍支持原判断，哪些只降低信心，哪些足以推翻判断。

给出优先核验的风险、证据及严重性理由、结论仍成立的条件和明确的失效触发点。不要自动更改观察记录或执行选股。
