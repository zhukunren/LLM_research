# 产业链研究

从用户指定的产业、需求变化或技术环节出发，梳理供需关系和可能的约束，解释谁提供什么、客户为何需要、替代方案是什么。

- 把材料、设备、制造、系统和终端需求连接起来。按重要性展开，不为画完整产业链而堆砌公司。
- 区分技术难点、产能短缺、认证门槛和实际议价能力；核查扩产周期、替代路线与瓶颈缓解条件。
- 对候选公司核验产品、客户或认证、收入敞口、产能与交付证据。概念相关、意向订单、实际出货和收入确认分别表述。
- 优先查看公司披露、客户或供应商材料、原始技术资料，并注意资料日期。多篇转载同一公告不能当作多项独立证据。
- 从需求、竞争、技术替代和资本投入角度寻找反证。不要把产业受益直接等同于股票回报。

围绕最关键的环节给出证据链、研究优先级及理由、不确定性、下一步验证点与失效条件。缺少证据的公司保留为待核实线索。
