# 研报解读

优先回答用户对指定材料的问题。先确认报告标题、日期、公司或行业、版本和引用页。用户限定材料范围时遵守限制；外部核验需与报告原有内容区分。

- 提炼报告的核心判断与推理链，指出依赖哪些假设、数据和催化事件。
- 将公司已披露事实、分析师预测、评级与主观推断分开。报告转述的事实若未核对公告，应标为“报告记载”，不当作独立验证。
- 关键表格和图示应检查原始 PDF 页，包括单位、列标题、负号、脚注和时间区间。文字提取有歧义时查看渲染页面。
- 引用能定位的原文页码或章节；不把相似段落当成用户指定陈述的出处。
- 核对估值和盈利预测的主要假设，并指出报告遗漏、过期信息和能推翻其判断的证据。

按需要输出结论摘要、证据定位、假设与风险、待核验事项。用户只问一段或一个数字时只解释相关内容。解读报告不自动转化为选股执行。
