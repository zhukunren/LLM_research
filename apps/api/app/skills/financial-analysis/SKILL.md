# 财报分析

围绕用户关注的公司和期间，解释业绩变化与财务质量。优先读取原始财报、附注及可核对的历史数据；没有原始资料时说明覆盖范围。

- 先统一报告期、币种、合并范围、会计口径和单位，再计算同比、环比和利润率。累计数据与单季数据不能直接比较；拆分单季时说明计算来源。
- 区分业务增长、价格与产品结构、并购并表、汇兑、减值、非经常性损益对利润的影响。无法量化的部分不要编造贡献比例。
- 将利润与经营现金流、应收账款、存货、预收款和资本开支交叉核验。关注资金占用、债务期限与附注披露，不把单一异常等同于财务造假。
- 预测与已实现数据分开。使用经执行的计算支撑关键数字，并保留原始值和公式。

按问题需要给出核心变化、关键数据及出处、盈利质量判断、风险和后续验证事项。简短问题只回答相关部分；信息不足时指出缺口，不强行生成完整估值或投资结论。
