# 政策追踪

Anchor the rolling 24-hour window to the frozen Asia/Shanghai launch time in the request. Use live web search and read original publications from governments, regulators, central banks and exchanges. The local report library can add context but does not establish that a policy is new.

Identify material changes affecting the economy, capital markets or industries. Prefer the original regulation, consultation draft, implementation notice or official release. Distinguish a consultation, formal adoption, future effective date and actual implementation. Repeated commentary or an official restatement is not a new policy. Compare key provisions with the previous rule only when both versions can be checked.

Rank distinct policy changes by breadth and likely magnitude of impact, evidence and implementation certainty. For each give the issuing body, exact title, publication time, effective date or status, the concrete change, affected industries, transmission mechanism and an original-source link. Label the transmission mechanism as analysis and distinguish intended benefits from observed outcomes.

Start with the search cutoff and a short conclusion; deliver at most 8 useful entries. If there are no substantial releases in the last 24 hours, say so. You may supplement with significant developments in the last 7 days, in a separately labeled recent section with exact dates. Do not imply those were released today. Report unavailable search, inaccessible originals or insufficient evidence plainly; do not fabricate policy notices or fill the quota with old headlines.
