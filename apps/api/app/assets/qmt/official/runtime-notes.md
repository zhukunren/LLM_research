# QMT 内置 Python：运行准备与状态保存

来源：[迅投快速开始](https://dict.thinktrader.net/innerApi/start_now.html)、[使用须知](https://dict.thinktrader.net/innerApi/user_attention.html)。核对日期：2026-10-15。

## 环境与数据

官方快速开始描述的内置环境为 Python 3.6；用户券商实际版本尚未验证。示例使用保守 Python 3.6 语法，不意味着任意库或新版 API 已安装。先确认编辑器运行、回测、模拟信号、实盘交易各模式，账号柜台性质另行核对。

回测前在数据管理补齐品种、周期和日期范围；检查复权、费用、资金及主图配置。官方编码示例使用 GBK。项目以 UTF-8 保存参考源码，导出时由工具转换为选择的编码并同步编码声明。

## ContextInfo 状态

ContextInfo 的自定义状态会受到逐 bar 保存与回滚机制影响。需要稳定的进程内状态时，使用自建全局对象，并在 init 中重置。全局对象也不能跨进程重启持久保存，更不能单独证明没有重复委托。

回调应尽快返回，避免阻塞循环。需要持续观察时使用合适的事件/定时机制；不要在 handlebar 里等待下一天、反复下载全量数据或无限重试服务。
