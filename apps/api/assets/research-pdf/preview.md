# 公司研究：证据、判断与下一步

这是固定模板的排版示例。内容用于检查中文、表格、分页和来源展示，不代表对任何公司的实际研究结论。

## 一、核心判断

围绕研究问题给出结论，明确事实、预测与推断。每一项判断保留对应的资料来源与数据日期。

- 事实：以公告或已核验原文为依据。
- 预测：记录假设及其适用范围。
- 推断：说明从证据到结论的推理过程。

## 二、关键证据与数据

| 研究事项 | 已知证据 | 待验证事项 |
| --- | --- | --- |
| 订单兑现 | 已核验公告与原文页码 | 收入确认节奏与回款 |
| 盈利质量 | 经营数据与计算口径 | 成本变化和现金流 |
| 反方证据 | 相反观点及对应出处 | 判断是否需要修订 |

## 三、验证计划

1. 确认数据截至日期与证券范围。
2. 核对原文、数值口径和计算结果。
3. 持续记录支持与反方证据。

## 四、失效条件与来源

写明哪些新事实会使当前判断失效。研报引用记录文档 ID 和页码，资讯引用记录来源 ID、发布时间；网页引用保留完整链接。

模板标识采用项目中已有的[东吴证券标识](https://www.dwzq.com.cn/)，营业部名称独立排版。
