# LLM 投研工作平台

研究公司、阅读资料、按条件找股票，并把证据和判断保存下来持续跟踪。

## 打开工作台

已完成首次安装后，双击项目根目录 **`start.cmd`**。浏览器会自动打开工作台，关闭启动窗口不会停止后台任务。日常使用无需打开终端或运行安装命令。

首次安装和连接配置由维护者完成，参见[维护与开发](docs/维护与开发.md)。如果界面尚未构建，启动器会提示维护者先准备用户版。

## 做第一件事

打开后直接进入研究对话，输入公司、行业或问题即可开始。界面保留东吴证券原始标识，采用浅灰侧栏、白色阅读区，并参照东吴证券官网的深蓝与亮蓝统一主要操作、选中状态和焦点提示。布局保持简洁；配色依据与正式 VI 核对边界见[品牌来源](apps/web/public/brand/SOURCE.md)。

1. **新研究**：输入问题后发送。需要参考时，展开输入框下方的 **示例问题**。已有对话的输入框始终保留在底部。
2. **开始选股**：点击左侧一级入口，选择基础方案或直接描述要求。基础方案展示实际规则与当前参数，展开 **调整参数** 可修改；先查看方案，核对股票范围、截止日与数据状态，再点击 **确认并开始筛选**。选择方案不会自动执行，也不要求先建立项目。
3. **资料与工具 → 研报库**：选择已有材料或上传 PDF，从原文发起研究。

研究、选股和资料处理的进展可在顶部 **运行任务** 查看。需要补充要求或处理失败时，打开原工作按提示继续；**最近任务**可找回已完成或需重试的任务。

## 第一次选股

- 基础方案使用固定的日线计算方法，不依赖模型解释：**收盘价在均线上方**、**区间涨幅超过阈值**、**短均线上穿长均线**。名称说明的是筛选规则，不是收益承诺。
- 自定义要求仍可用自然语言描述；不支持或资料不足的条件不会被静默删除。数据提示只说明来源可用性，逐证券覆盖与最终判断以执行结果为准。
- 结果默认查看 **符合** 项，同时展示截止日、判断覆盖和数据不足数量。展开股票可以查看实际条件与依据，也可以切换查看全部判断。
- 无匹配、数据不足和运行失败分别提示；系统不会自动放宽规则凑出结果。得到结果后再决定保存方案或加入观察。

## 获得结果后

- **保存为研究笔记**：保留答复和出处。独立研究归入研究收件箱，项目研究归入当前项目。PDF 在后台生成，正文保存后可以继续工作；排版失败可以单独重试。
- **加入观察**：按公司名称或六位代码选择公司，检查系统带入的关注理由。验证计划和失效条件可以之后再补充。
- **转为选股草稿**：带入研究摘录和原出处，可继续修改。在条件选股中确认方案后，再决定是否执行。

项目和观察池以列表与正文为主，减少重复统计卡。研究答复连续展示，代码仍可按需展开。独立条件和高级组合用于长期复用要求，可在需要时展开。资料页默认以搜索和阅读为主，点击 **选股与条件工具** 展开进阶能力；形态页的匹配参数集中在 **匹配设置** 中。

点击 **成果与文件** 从右侧查看研究文件；点击答复中的研报或资讯引用，在右侧核对原文。研报会定位到引用页，也可在新窗口打开。关闭面板后继续原对话。

## 下次继续

点击左侧 **最近对话** 中的记录继续。具体对话、项目和观察记录有独立地址，可以保存书签；刷新和浏览器返回可回到原工作。未发送的草稿会保留，旧首页书签会自动进入新研究界面。

左侧提供 **开始选股**、新研究、搜索、研究项目、观察池、研究助手和历史记录。资料库放在 **资料与工具** 中，数据状态在 **数据与服务** 查看。手机点击左上角菜单打开导航。

**研究助手** 是一级菜单，展开后有 **通用投研、财报分析、研报解读、产业链研究、风险复核** 五个子入口。点击所需助手即可打开已配置好的新研究，无需自行创建或填写方法。输入框旁也可以切换助手。每次发送会保存所用方法的版本，后续修改不会改变历史研究。

按 **Ctrl K**（Mac 使用 **⌘ K**）打开快速导航，可直接找回最近对话、项目或页面，也支持用空格组合关键词。研究页面点击示例问题只填入草稿，确认后再发送；**Enter** 发送，**Shift + Enter** 换行。

## 数据与服务

页面显示实际行情日期和质量状态。行情可查询、探索筛选可执行、正式选股就绪是不同状态，请按当前任务提示核对所需数据。

连接异常时重新双击 `start.cmd`；仍有问题，在 **数据与服务** 中重新检查并保存诊断信息交给维护者。

## 更新本地版本

维护者拉取最新代码后，在 `apps/web` 运行 `npm run build`，然后重新启动服务；只拉取源码不会更新已有的 `dist` 界面。此次选股易用性更新不需要新增依赖，基础方案仍需用户确认后执行。
