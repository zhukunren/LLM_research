## 启动

要求 Windows、系统 Python 3.12、Node.js 20 或更新版本。应用直接使用系统 Python；Python 依赖安装到项目的 `runtime/python-deps/`，不创建虚拟环境，也不覆盖系统/用户的其他项目包。

```powershell
.\scripts\bootstrap.ps1
.\scripts\start.ps1
```

浏览器打开启动脚本打印的本地地址。停止服务：

```powershell
.\scripts\stop.ps1
```

重复执行启动脚本会复用健康的本地服务。更新后端代码后运行 `.\scripts\start.ps1 -Restart`；脚本核对进程命令与创建时间，只重启本项目记录的服务。worker 中断的任务在 90 秒租约过期后重新排队，连续中断三次后转为失败，可在界面手动重试。

API 文档可通过 `/docs` 查看。启动脚本只绑定 `127.0.0.1`；API、后台筛选 worker 和 Vite 前端分别运行。服务日志放在 `runtime/logs/`。

## 功能范围

新版对话工作台采用普通Python自定义计算和本地子进程。以下涉及固定指标、公式白名单、直接加载源码和审计哈希的描述属于旧入口兼容功能，不是新对话筛选的技术路线或当前验收要求。

- 一段描述可生成多个原子条件，保留且、或、排除和括号关系。完整本地解析或模型生成经过白名单与完整性检查；无法理解、缺少数据或服务失败时明确提示，不用默认条件替换意图。
- 中文条件卡片支持调整周期/阈值、单股试算和确认保存；原话、模型、规则版本、人工修改均可追溯。条件更新创建新版本，确认请求可安全重复提交。
- 自由组合条件版本，选择全部 A 股或自建股票池；提交时固定股票池、条件版本与对应研报评估。全部股票的判断均保存，包括未命中和数据不足，支持分类、搜索、分页和导出。
- 新任务有执行协议兼容检查，已完成结果由数据库禁止覆盖。启动/停止脚本核对项目路径后清理残留服务。
- 浏览本地证券日线，按截止日查询最多 500 根 bar。常见指标使用固定算法；指标库未覆盖的新时序指标由模型生成带参数和中间值输出的 Python 源码模块，系统按固定行情输入、只读一维数组、受限源码语法、计算步数和逐日输出合同直接加载执行，并保存源码版本与哈希。复权口径未知，数据只用于明确标记的探索分析。
- 资讯、技术和研报条件支持文本生成草稿、表单校正、结构校验和版本保存。研报自然语言目标会整理为可编辑的判断维度、判断问题、支持/反向信号、组合关系和回溯期；本地模板是无模型时的编辑起点，不代表模型已评估。
- 配置模型后，可异步评估截止日和回溯范围内的本地研报。结果按条件版本、文档哈希、rubric 哈希、模型和提示词版本缓存；只有引用能在所标页原文中核对时才接受 true/false，false 必须有明确反向证据。无证据、模型错误、代码未确认、未知日期、未覆盖范围都保留 unknown/partial。
- 研报库可索引本地 PDF 或上传 PDF，保存逐页文本并按关键词返回页码引用。文本命中不代表语义事实已经核实。
- 形态浏览与“我的形态”默认显示匹配度最高的真实 K 线；描述需求中提供文字、手绘、OHLC 编辑及截图输入，可直接匹配本地市场，保存后可切换查看原始曲线。
- 策略固定引用条件/形态版本，支持 AND、OR、NOT、嵌套组、评分权重和 TopN。探索运行由 worker 扫描全市场；正式运行在必要数据口径核实前会被阻断。
- 同一技术条件可在策略中多次引用，分别覆写周期、数值阈值或均线穿越方向；覆写按原条件类型和范围校验。策略编辑与观察池可选择历史版本，完整保留嵌套取反结构。研报口径调整需另存条件版本并重新评估。
- 新保存的 OHLC 模板同时比较走势、实体、影线、涨跌方向和跳空；旧模板保留原算法，重新保存才生成使用新算法的版本。匹配预览展示模板与行情路径及分项差异，相似度不是收益概率。
- 筛选与研报任务支持取消和重试。重试建立新运行并保留原记录，同一重试请求不重复创建任务。研报条件重载后可找回最近一次评估；观察池支持编辑备注，历史结果的 K 线按该运行截止日读取。
- 新观察池按运行批次保留入选记录，逐股观察状态与备注独立保存，不修改原选股结果。

文本模型配置读取项目根目录 `config.ini` 中的 `[app]`、`[model_providers.OpenAI]`、`[secrets]` 段。模型凭证不会返回浏览器或写入日志；`config.ini` 已加入 Git 忽略。当前配置使用 Responses API。设置页的连接测试只发送固定短提示，不发送研报文本。Tushare 中转读取 `[tushare]` 的 `relay_api_key_env`、`relay_base_url`、`timeout` 和 `retries`；未显式配置密钥时，适配器会使用其自身的本地默认配置。

## 备份与恢复

默认备份保存 SQLite 一致性副本、用户上传件，并为大型原始行情/研报文件记录路径、大小与 SHA-256：

```powershell
py -3.12 scripts\backup.py D:\ResearchBackups\2026-09-25
py -3.12 scripts\restore.py D:\ResearchBackups\2026-09-25 D:\RestoredResearch
```

若备份需要携带原始行情和 PDF，添加 `--include-source`。恢复命令只写入一个不存在的新目录，不覆盖现有文件。

恢复前会核对上传件和备份内原始文件的 SHA-256；恢复后会更新已复制研报的本地文件路径。使用 `--include-source` 恢复后，将 `LLMR_DATA_ROOT` 指向恢复目录的 `source/`；未携带原件的备份仍依赖清单记录的原始文件。
