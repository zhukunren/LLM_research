# LLM 投研工作平台

研究公司、阅读资料、按条件找股票，并把证据和判断保存下来持续跟踪。

## 打开工作台

已完成首次安装后，双击项目根目录 **`start.cmd`**。浏览器会自动打开工作台，关闭启动窗口不会停止后台任务。日常使用无需打开终端或运行安装命令。

首次安装和连接配置由维护者完成，参见[维护与开发](docs/维护与开发.md)。如果界面尚未构建，启动器会提示维护者先准备用户版。

## 做第一件事

左侧顶部使用 **研究 / 选股** 切换工作区。研究侧提供新研究、研究项目和最近研究；情报台独立承接市场简报、政策追踪与产业跟踪；研究方法在对话输入框中选择。选股侧栏提供 **新选股、选股方式、我的方案、筛选记录**。**选股方式** 目录包含技术、形态、资讯、研报四个独立入口，首次默认收起、记住用户的展开状态，进入专用页面时自动展开并高亮；新选股页继续提供四种方式卡片。**我的方案** 统一查找对话方案和条件组合，并提供 **新建条件组合**、继续编辑及 **管理条件库**。两类方案保留各自模型与版本，不自动转换；**筛选记录** 集中查看历史运行与结果，最近选股作为快捷记录保留。QMT 脚本生成位于 **更多工具** 中。旧条件库、形态库、组合编辑与运行记录地址继续有效。两侧分别保留所在位置、未发送草稿和历史记录；切换工作区不会启动研究或筛选。

**我的方案** 可按类型和名称查找方案，条件组合支持展开历史版本并 **打开编辑**，不会自动执行；当前组合草稿可直接继续。规则编辑为主工作区，点击 **添加条件** 按需展开搜索与分类侧栏，空草稿默认展开；收起保留搜索和勾选。全部满足、任一满足、整体排除与嵌套分组保留，单项参数就地调整仅作用于当前组合，完整逻辑可展开核对。新增条件仍通过描述、核对、保存后加入当前草稿，不另建平行编辑器。条件库使用紧凑管理列表，点击名称先查看口径、来源与历史版本，再明确 **编辑条件**；库内修改保存为新版本，不静默改动已有组合的固定引用。底部 **排序设置**、**保存组合** 和 **开始筛选** 保留；组合版本保存名称、规则与保留数量，股票范围和截止日期用于本次运行，并非组合持久字段。运行历史保留原快照，不随草稿变化；手机通过待选条件与返回规则切换，使用同一份草稿。新建或切换组合保留最近一次可撤销快照，不是多份未保存草稿仓库。

打开后直接进入研究对话，首先提供 **看懂一只股票 / 按条件找股票 / 读懂一份研报**。选择股票可按名称或代码搜索，并选择经营变化、主要风险或同行比较；选择只会填入可编辑的问题，点击发送才开始研究。找股票和读研报分别打开选股对话及研报资料入口。也可以直接输入公司、行业或问题。界面保留东吴证券原始标识，采用浅灰侧栏、白色阅读区，并参照东吴证券官网的深蓝与亮蓝统一主要操作、选中状态和焦点提示。布局保持简洁；配色依据与正式 VI 核对边界见[品牌来源](apps/web/public/brand/SOURCE.md)。

1. **新研究**：输入问题后发送，按问题中的公司、行业或时间要求展开，不需要先设置研究范围。通用研究显示三个任务入口；带有资料或特定范围的研究继续提供相关示例问题，点击只会填入草稿，确认后再发送。已有对话采用大幅阅读区与底部输入框；项目归属和成果文件在页头查看。
2. **开始选股**：点击左侧一级入口，直接描述要求，或展开 **选股示例** 选择基础方案与示例。选股使用与研究对话相同的页面：对话和输入框常驻，筛选方案与结果在右侧抽屉，页头按钮可随时打开或关闭。基础方案标为 **固定规则**，展示实际规则与当前参数，展开 **调整参数** 可修改；示例标为 **模型理解**，点击只填入草稿。核对股票范围、截止日与数据状态后点击 **生成并筛选**；想先核对方案，可在 **选股设置** 中点击 **只生成方案**，在右侧抽屉确认后点击 **开始筛选**。选择基础方案会直接生成并自动执行，不要求先建立项目。
3. **资料库 → 研报与公告**：选择已有材料或上传 PDF，从原文发起研究。

研究对话实时显示 Codex 正在搜索网页、阅读资料、核对图表或计算数据，并展示助手公开的进展说明，提供用时与停止操作。展开 **查看研究过程** 可检查活动记录，回答完成后也可以回看。研究、选股和资料处理的进展也可在顶部 **运行任务** 查看。需要补充要求或处理失败时，打开原工作按提示继续；**最近任务**可找回已完成或需重试的任务。

研究报告 PDF 保留东吴证券原始 logo、张家港营业部名称和标题封面。正文按问题自由组织，不要求填写固定研究字段，也不强制摘要或章节结构。

研究输入区默认使用服务配置或已保存的个人选择，无需先选择模型。展开 **研究设置** 可以选择研究方法、模型与推理档位，并打开我的指标；选股侧继续在 **选股设置** 中选择模型。当前账户无法使用的模型显示为灰色，并说明原因；Free 账户下 Astra 和 Sol 不可选。每次发送保存当轮的模型与档位，之后切换不会改写历史研究。

## 新增可复用条件

从 **我的方案 → 管理条件库 → 新增可复用条件** 进入，可选择 **技术条件、形态条件、资讯条件、研报条件**。技术条件先选择单条规则并调整参数；复杂需求可切换 **描述自定义条件**，保留原有描述、核对与试算流程。形态条件选择已有目标的固定版本，设置相似度和匹配窗口，保存独立的来源副本并保留原模板。

资讯与研报条件明确原文判断要求、相对时间窗口和事实口径；资讯还可指定事件状态与独立事件数，样本验证会返回实际原文摘录或数据不足，不降级成关键词命中。样本验证读取所选公司与截止日前的资料；缺少模型或资料时可保存定义，执行时继续明确依赖状态。读取失败和验证未完成不会当作没有匹配。

参数化创建先 **验证样本 → 命名 → 保存为可复用条件**。修改规则或样本后需重新验证，修改名称不要求重算。验证记录与规则相绑定，重复保存返回同一资产；保存不会运行全市场筛选。点击 **将此版本加入组合** 才加入当前草稿，并固定条件或形态版本。条件库统一展示四类，形态详情可选择历史版本；创建时的验证信息可展开回看。

## 描述和复用我的指标

在研究对话的 **研究设置 → 我的指标** 或选股对话的 **我的指标** 中，描述想计算的数值公式，确认草稿并发送给 Codex。流程是 **描述需求 → 生成并试算 → 看图确认 → 保存或用于选股**。任意可用日线字段上的计算都可以生成，范围不受内置指标目录限制；缺少的数据、单位或频率会明确提示。**常用指标**也在同一面板中，包含均线、MACD、RSI、布林带、KDJ 和 ATR，可调整证券、周期与截止日，按原有固定公式预览行情与曲线。点击 **带入对话生成可保存版本** 后，核对生成的完整试算再保存、修改或用于选股。常用预览本身不会创建已保存版本。

独立指标库页面及导航入口已取消，旧指标库书签会转到研究或选股对话的 **我的指标 → 常用指标**；已打开或已关闭待恢复的旧指标库标签也会迁移。底层内置计算接口、已保存指标的版本与试算记录继续保留，共用图表仍用于行情、形态和公司研究。

- 数值指标使用 `python-indicator-v1`，逐日输出完整日期与数值序列；布尔选股条件继续使用 `python-screen-v1`。指标曲线不会被截为选股解释指标的短摘要。
- “我的指标”保留当前对话的试算和已保存指标。可选择证券、截止日、历史长度和参数重新试算，并查看完整 K 线/指标图、预热缺口、公式/源码、数据口径与验证证据。更改输入后需重新试算，旧图不会冒充新参数的结果。
- 点击保存才创建不可变版本，记录公式/源码及哈希、有效参数、数据上下文和真实试算证据。修改后保存新版本，不覆盖历史；相同保存请求可安全重试，版本冲突或试算后数据变化会要求刷新/重试。
- “用于选股”明确选择数值输出、比较方式和阈值，生成未发送的选股草稿。研究侧打开独立选股对话；选股侧继续当前草稿。生成布尔条件时冻结指标版本、源码、参数和实际试算历史长度；改变历史长度后需保存新版本，避免 EMA 等累计计算与所见曲线不一致。仍需核对方案与范围，并遵循原有正式执行授权流程。保存或试算不会自动执行选股。
- 自动验证覆盖数值/有限性、输出形状、完整日期对齐、预热和缺失值，并对多个历史前缀复算以发现常见前视错误。这些是有限样本证据，不证明金融含义正确、投资有效、完全无前视偏差或代码安全。生成 Python 仅适合可信本地使用，沿用有资源限制的独立进程，**不是操作系统安全沙箱**。

开发接口为 `/api/v1/dynamic-indicators` 下的 `preview`、`save`、`trials`、版本读取和 `/{id}/condition`。Codex 使用 `preview_dynamic_indicator`、`read_indicator_trial`、`list_dynamic_indicators`、`read_dynamic_indicator`；`build_indicator_condition` 仅在选股工作流开放。新增 `038_dynamic_indicators.sql` 由应用初始化迁移；更新前备份数据库，更新后重新构建网页并重启服务。

## 自然语言生成 QMT 脚本

打开 **选股 → 更多工具 → QMT 脚本生成**，选择信号观察、策略回测或交易策略草稿，描述股票范围、周期、信号、仓位与退出要求。可点击均线交叉、放量突破等示例填入需求，点击 **带入生成对话** 后选择模型并发送。工具面向 **券商 QMT 客户端内置 Python**，支持在同一对话继续修改、预览完整代码和下载 `.py` 文件，默认使用 GBK 编码，也可选择 UTF-8。

生成助手通过 `validate_qmt_script` / `export_qmt_script` 检查语法、`init` / `handlebar` 入口、编码及常见环境混用，导出不可覆盖的版本文件。静态检查不会运行脚本、连接券商或提交委托，也不证明策略收益或完全无前视偏差；需在实际券商 QMT 版本中验证和回测。交易策略默认关闭实盘开关，账号留空。

工具页展开 **参考资料** 可搜索和阅读官方接口参考、项目策略编写手册及源码示例。助手先通过 `search_qmt_docs` / `read_qmt_doc` 查阅正文，再生成和导出；第 2 版 QMT 助手导出时检查本轮真实查阅记录，缺少常用接口资料会提示补读，导出结果记录实际来源与版本。官方资料保留原文入口，本地参考不是官网完整镜像，项目示例也不声称通过券商客户端验证。[资料目录与维护方式](docs/qmt/README.md)。

## 按方式选股

四个专用入口可从侧栏、新选股首页或快捷搜索进入。技术、资讯和研报页分别保留未发送的要求、股票范围、截止日期与表单参数；切换标签或刷新不会把另一入口的草稿带过来。正式提交后使用同一套选股对话、方案、结果、证据与运行记录。

- **技术选股**：直接选择均线、区间涨幅或均线交叉等固定规则，调整参数并查看完整口径。**试算规则** 对选定的一只股票展示符合情况、计算值和真实行情图，不创建方案、不运行批量筛选；参数、证券或日期变化后必须重新试算。**开始筛选** 按固定日线规则执行，不依赖模型。切换 **描述自定义条件**，或补充资讯、研报等要求后，通过模型组合条件；仍可选择 **只生成方案**。
- **资讯选股**：设置股票范围、截止日期和资讯发布窗口，描述事件与判断要求。提交要求包含股票名单、事件关联和原文依据；资料不足单独列出。查看资讯原文可打开资料库，保留本页草稿。
- **研报选股**：设置研报发布窗口，并选择已发生事实、分析师预测，或分别核对事实与预测。提交后逐只判断，并要求提供研报日期、页码和原文；发布日期窗口不等同财务报告期。
- **形态选股**：共用原形态库的行情区间、截图、文字与绘图工具。**保存并用于选股 / 按此形态选股** 将固定模板版本和匹配参数加入当前条件组合；已打开的组合编辑页同步收到新增条件，保留已有规则。核对股票范围与截止日期后，再开始正式筛选。形态相似样本及其研究记录继续用于对照。
- **条件组合**：从已保存条件与形态中编排全部满足、任一满足、排除和嵌套关系。组合版本、对话方案和历史运行仍按各自原契约保存，不静默转换或覆盖。

已有筛选方案可点击 **叠加条件**，追加技术、资讯、研报或已保存形态条件。操作先把修改要求放入当前对话；发送后才修改并重筛。已有输入、原方案关系、股票范围和截止日期保留，形态依据固定到选择的版本。**我的筛选方案、全部筛选记录、观察池** 统一承接各入口的结果。

专用入口地址为 `#/screening/method/technical`、`#/screening/method/pattern`、`#/screening/method/news`、`#/screening/method/report`；原对话和组合地址继续可用。维护接口新增 `GET /api/v1/screening-templates?include_singles=true` 和 `POST /api/v1/screening-templates/{id}/preview`；试算只读行情并沿用现有公式与数据完整性判断，不发布任务或写入运行记录。

## 第一次选股

- 输入框下方提供 **技术选股、形态选股、资讯选股、研报选股** 四个入口，并可打开 **条件组合**。点击只进入相应工作区，提交要求或点击开始筛选后才执行；自由描述、完整示例和数据说明仍保留。

- 展开输入框下方 **选股示例**，可选择三个固定规则组合：**趋势走强**（收盘价高于20日均线且近5日涨幅大于3%）、**均线上穿确认**（5日均线上穿20日均线且收盘价高于20日均线）、**上穿并加速**（5日均线上穿20日均线且近5日涨幅大于3%）。每组必须同时满足两项条件，不展示走势图。点击先展开预览，可调整参数，公式与说明按需展开；生成方案后自动开始筛选。如需先核对方案，可在 **选股设置** 中点击 **只生成方案**；已有方案修改时可在 **选股设置** 中点击 **只改方案**，确认后再点 **开始筛选**。各项采用固定日线算法，不依赖模型解释；旧方案与历史请求继续可用。
- 方案生成、执行进度和结果数量先在对话内同一张卡片中更新，载入或完成时不会自动弹出详情、移动焦点。点击 **查看方案 / 查看名单** 或页头 **筛选方案与结果** 打开详情；宽屏并排显示非模态侧栏，窄屏由用户点击后打开底部详情层。方案和结果分标签阅读，关闭后保留聊天位置与输入草稿。抽屉顶部用 **我的理解** 复述条件、范围和数据日期，并在每条条件下并列 **你的原话** 与 **系统规则**；待澄清问题直接在对话卡片中填写；点击 **补充并继续筛选** 后连同草稿一起提交。原要求只生成方案时，按钮为 **补充并更新方案**，继续保留暂不执行的要求。
- **选股示例 → 看看还能筛什么** 按行情、研报、资讯、形态列出示例，标为 **模型理解**，点击只填入草稿；输入框上方写明当前可筛与暂不筛的数据范围。输入估值、财务、历史行业/ST、分钟线等暂不支持的字段时，输入框下方会提示可替代的方向，不会静默忽略。
- 模型与条件核验深度集中在 **选股设置**，沿用已选配置或服务默认值。模型不可用或读取失败仍在输入区提示，不会自动替换模型。保存、命名与项目归属在方案抽屉的次级操作中。
- 自定义要求仍可用自然语言描述；不支持或资料不足的条件不会被静默删除。数据提示只说明来源可用性，逐证券覆盖与最终判断以执行结果为准。
- 正常数据说明默认收起，来源已接入不保证全部条件可执行；异常自动显示原因与处理入口。结果默认查看 **符合** 项，突出符合数、已判断覆盖与数据不足数，处理失败和未处理另行说明。展开股票可查看实际条件与依据，也可切换全部判断。**复制与导出** 菜单分别提供本页代码、当前搜索范围全部符合项和当前状态/搜索范围全部页导出。
- 无匹配时给出参数级调整建议（例如把涨幅阈值从 3% 放宽到 2%），点击只填入输入框；数据不足提供 **更新数据** 和 **缩小范围**；有符合项时结果顶部提供 **保存为方案**。系统不会自动放宽规则凑出结果。得到结果后再决定保存方案或加入观察。

## 获得结果后

新完成的研究可在正文上方显示结构化 **研究摘要**：一句话判断、事实与推断、主要风险、待验证事项和资料日期；摘要由该轮研究生成并保存，不从正文标题猜测或补写，缺少有效摘要的历史答复继续显示完整正文。每条研究答复直接提供文字按钮 **加入关注** 与 **查看依据**；复制、分享、重新生成和保存笔记继续使用紧凑图标。加入关注带入可编辑的摘要与待验证事项，旧回答沿用正文摘录。点击 **⋯** 可打开新对话分支或转为选股草稿，也保留来源入口。来源汇集回答正文、所链接完整报告中的引用，以及该轮实际查阅的原文；工具查阅记录单独标为 **研究中查阅**，搜索发现不会自动当成已经阅读。历史回答也可补回来源，读取失败显示错误与重试按钮。

点击 **分享 → 创建分享链接**，生成可在其他设备匿名打开的 HTTPS 链接。接收方查看的是截至所选回答的只读快照，包括此前对话、来源链接、保留的原文摘录和对话链接的 Markdown/文本完整报告；后续追问、重新生成或修改资料不会改变已有快照。可以复制链接、下载对话文件，或 **撤销分享链接**。最近研究菜单里的分享以最新已保存的助手答复为截止点。只有点击创建链接时才上传所选快照，整个本地工作台不会对外开放。

最新答复 **重新生成** 使用原问题、附件、模型、助手版本和研究范围，保留原回答，通过回答下方的箭头切换版本。对较早答复重新生成会自动创建独立分支，保留后续对话。**打开新对话分支** 只复制截至所选回答的历史与附件，可继续追问，不会自动启动研究。操作重试会复用同一请求。

- **保存为研究笔记**：保留答复和出处。独立研究归入研究收件箱，项目研究归入当前项目。PDF 在后台生成，正文保存后可以继续工作；排版失败可以单独重试。
- **加入观察**：按公司名称或六位代码选择公司，检查系统带入的关注理由。验证计划和失效条件可以之后再补充。
- **转为选股草稿**：带入研究摘录和原出处，可继续修改。在条件选股中确认方案后，再决定是否执行。

项目详情默认收起研究目标与关联公司，手机标题与操作分行展示；编辑笔记时优先显示正文。形态编辑可点击 **专注绘图** 放大操作空间，按 Esc 返回，已有形态默认从绘图区开始。组合筛选、对话筛选和历史记录统一使用 **紧凑列表**，点击 **查看依据** 在侧栏核对完整判断、公式计算与原文证据；勾选本页股票后可复制、导出所选或加入观察池。**切换筛选记录** 可搜索名称、日期或运行状态；旧版记录保留原有优先结果、数据快照与导出口径。观察池将股票搜索、所属、状态和已保存视图合并到同一工具栏，统计压缩为随筛选更新的摘要行。**排序与视图** 提供排序、保存与清除筛选；**保存当前筛选** 会把查询、所属、状态和排序保存在当前浏览器。行内保留重点关注、状态和备注编辑，删除、上移、下移统一进入 **更多**，本页批量操作在勾选后出现。

形态库支持 **指定股票与区间 → 载入 K 线**：选择股票及起止日期，载入 10–250 根实际交易日的未复权日线。可按完整 OHLC 蜡烛或收盘路径匹配，价格归一化后展示最多 12 个相似样本。匹配沿用本地每只股票最近 120 个结束窗口、每家公司取最相近区间，排除来源股票。保存模板时保留股票、日期、价格口径和原始行情快照，后续行情更新不会改写模板；日期或股票修改后需重新载入。新增 `052_pattern_market_windows.sql` 迁移由应用初始化执行。

形态库默认进入 **形态匹配** 工作台：一个目标形态共用行情、手绘、截图与文字工具。打开或关闭工具保留当前目标和各工具输入；行情、截图与文字的新结果先核对，再 **应用候选**，并可 **撤销应用**。真实行情保持只读，需要修改时 **复制为自定义形态**；截图与文字转为手工编辑后仍保留衍生来源。新检索默认使用最新可得行情；标题工具栏的 **研究记录** 抽屉独立复查旧请求、截止日期与冻结结果，不改变当前草稿。保存更新当前模板版本，**另存为副本** 创建独立模板；已保存模板从 **我的形态 → 载入对照** 打开。选股参数与详细口径按需展开，窄屏按纵向布局展示。

项目和观察池以列表与正文为主，减少重复统计卡。观察池将研究、手动关注和筛选入选记录放在同一列表，用 **所属** 列标明研究项目或筛选批次，并可按所属、状态和股票搜索筛选。列表显示加入时间、至今涨跌幅和按有效日线收盘价计算的最大回撤；顶部汇总随筛选更新。研究与手动记录从加入日起算，选股记录从批次信号日起算；复权口径未确认时界面会提示数值局限。研究答复连续展示，代码仍可按需展开。独立条件和高级组合用于长期复用要求，可在需要时展开。资讯与研报共用 **资料库**；阅读页的 **用于选股** 将出处带入统一选股草稿，条件库和证据评估不再在资料页重复设置；形态页在目标图旁调整交易日数，图下方的 **匹配相似形态** 发起对照，最低相似度和匹配窗口集中在保存区域的 **选股设置** 中。

资料库的 **研究当前资料** 与 **用于选股** 集中在阅读区，资讯、研报和原始披露使用相同入口；PDF 会带入当前文档及物理页，切换资料后沿用新的阅读对象。资料列表标题旁的 **资料管理** 菜单集中提供网址导入、上传 PDF、本地研报索引及原始披露归档、分类核对和修订关联；导入资讯在侧栏填写，关闭后保留未完成的网址。\n\n点击 **成果与文件** 从右侧查看研究文件；点击答复中的研报或资讯引用，在右侧核对原文。研报会定位到引用页，也可在新窗口打开。关闭面板后继续原对话。

输入框左侧的 **＋** 可以上传文件，旁边的 **研究方法** 可选择财报分析、研报解读、产业链研究或风险复核。选择方法保留草稿和附件，发送后才开始研究。附件保存在当前对话里，可上传 PDF、Word、Excel、PPT、CSV、文本和常见图片；每份最多 25 MB，每次提问最多 8 份。选好文件后输入问题并发送，也可以只发送附件让助手分析。已发送的附件可从消息中重新下载，未发送的附件可以移除或重试上传。

模型与推理强度在输入框右侧、发送箭头旁选择。需要表格或文档时，在问题中直接说明文件格式；助手可生成 Excel、Word、PPT 等原格式文件，答复中的文件链接及页头 **成果与文件** 都可以下载。原格式文件与品牌 PDF 报告同时保留。

股票名称与代码在对话和各类面板中以蓝色标出。点击可打开日线行情，悬停或键盘聚焦可选择 **加入观察池**；手机打开行情后也可加入。匹配使用证券目录和已确认的常用简称，不猜测重名公司；行情显示实际数据截止日。快速加入为手动关注，不生成研究或筛选任务，已有观察不会重复创建。

## 公司研究、同业对比与质量评测

研究项目中可从 **公司研究** 直接选择关联公司，在同一处核对行情、最近资料时间线、已保存判断、验证计划、失效条件和观察记录。点击 **继续研究这家公司** 会创建带公司与截止日范围的新研究对话；保存的论点保持原笔记版本，笔记更新后会提示旧依据待复核。

项目的 **同业对比** 支持保存 1–10 家公司、1–6 项问题的模板。可创建空白对比手动核对，或点击 **根据本地资料生成**，后台按公司处理并保留可恢复检查点。资料在开始时冻结，生成使用有界摘录并记录实际覆盖；未找到证据不会自动解释为公司未披露。每格可打开保存的原文、补充引用并留独立修订版本，保留与上次运行的差异，也可导出含依据与口径的 Excel。耗时和供应商返回的 token 用量可在生成记录中查看。

公司页的 **资料与研究变化** 首次建立基线，之后按当前截止日比较新增或修订的资料，以及保存研究的版本变化。检查结果会列出原有验证问题，复核记录由用户保存；系统不会仅凭新材料自动改写论点。该入口按需检查，不会自动安排通知或定时任务。

项目的 **质量评测** 检查保存引用能否定位、资料是否符合截止日，以及笔记版本是否已变化。这些检查不替代语义判断。维护者可运行 `scripts/benchmark_research_quality.py --mode validate` 校验冻结题库，使用 `--mode live` 对真实模型运行 31 项公开财报摘录任务，或用 `--mode grade --responses <results.json> --suite <原运行的suite.json>` 复评答案；`--case-id` 可重复指定题目。题库覆盖数字、单位、报告期、历史时点、缺数和口径不明确时的拒答。每次输出题库快照、模型用量、耗时、结果 JSON 和 `human-review.csv` 人工评审表（含人工核验秒数填写栏）；配置 `--input-price-per-million` 与 `--output-price-per-million` 后按供应商 token 用量估算费用。自动通过只说明结构化事实与标准答案一致，仍需人工检查结论、反证与推导。原有开放式研究验收脚本 `evaluate_research_quality.py` 继续用于完整研究过程评审。

以上功能使用 `040_research_workbench.sql` 迁移，由应用初始化执行。更新前备份数据库；前端重新构建，API 和 worker 更新后再使用辅助生成。

## 下次继续

顶部标签栏支持同时打开多个功能页和研究。点击左侧功能或最近研究会打开独立标签；已打开的页面会切回原标签，点击 **新研究** 或标签栏 **＋** 可再开一份草稿。各标签保留自己的草稿、附件与阅读位置，刷新后恢复标签和草稿；关闭标签不会停止已提交的后台任务。拖动标签头可调整顺序，顺序在刷新后保留；聚焦标签头后也可按 Ctrl（Mac 使用 ⌘）+ Shift + 左右方向键调整。右键点击标签头，可关闭当前标签、关闭其他标签、关闭左侧标签、关闭右侧标签或关闭全部标签；左右按当前排序判断，保留右键点击的标签，该侧没有标签时对应操作不可用。关闭全部后保留一个空白研究页。菜单中的 **重新打开关闭的标签** 可逐个恢复最近关闭的标签与草稿，当前浏览器会话保留最近 20 条关闭记录，刷新后仍可恢复。标签栏支持左右方向键切换，Delete 关闭当前聚焦的标签，Shift + F10 打开标签右键菜单。桌面布局收紧导航、工具栏和面板间距，并随宽屏加宽研究正文；手机继续使用触控布局。

在 **最近研究** 的记录上悬停，点击 **⋯** 可重命名、置顶、分享、归档、删除或移至研究项目；手机直接点击 **⋯**。点击列表标题旁的 **已归档** 可恢复对话，研究分享支持公开快照链接和完整对话文件。

点击左侧 **最近对话** 中的记录继续。具体对话、项目和观察记录有独立地址，可以保存书签；刷新和浏览器返回可回到原工作。未发送的草稿会保留，旧首页书签会自动进入新研究界面。

研究侧以 **新研究** 为首个入口；切换到选股侧后，以 **新选股** 为首个入口。方案中心中的 **对话方案** 使用紧凑列表，行内提供 **按最新行情运行**；**详情** 展示原截止日、保存版本、完整条件与排序逻辑，并可 **按原日期运行**。完整方案复用后会自动开始筛选；最新行情日期未就绪时禁用最新日期复用，仍可在详情中选择原日期。对话内的已保存方案入口使用相同列表，详情在当前侧栏内切换，返回后保留搜索。资料库在侧栏共用入口打开，数据状态在 **数据与服务** 查看。手机点击左上角菜单打开导航，顶部同样可切换研究与选股。

## 情报台：市场简报与证据版本

侧栏 **情报台** 提供市场简报、政策追踪与产业跟踪。打开入口只读取已有成果，不会自动启动模型。选择市场、近 24 小时 / 3 天 / 7 天、行业、来源偏好和条目上限，点击 **生成简报** 或 **更新简报**。可指定北京时间的历史截止时刻；留空则冻结提交时刻。最近一次提交的范围会保存为默认值。

执行进展来自后台实际检索、原文读取和成果校验记录，显示已保存的来源数。可以离开页面、重新打开或停止任务；连接中断后 **继续提交** 复用同一请求。服务未就绪时可恢复原执行，失败或停止后可按原范围新建重试版本。

每项成果分别呈现事件事实、影响分析、排序依据、关联对象、原文摘录和下一步核验事项。证据侧栏读取本版本保存的正文快照，高亮已定位的摘录并提供原网址；未找到发布日期或只有日期而无精确时间时，明确标为待核验。引用定位和时间检查不替代语义判断。来源读取失败与没有可靠更新分别呈现，不能把抓取失败当作没有事件。

**历史版本** 保存每次的范围、截止时间、执行状态和交付物；同范围版本按事件标识标出新增、变化和延续，并保留本期未列入的上期条目。旧版本不会被覆盖，可导出简报或就某项事件继续研究。旧快捷任务的聊天记录在历史面板中保留。情报成果地址为 `#/intelligence/{market|policy|industry}/{id}`，原研究和资料书签继续可用。

本轮新增 `042_intelligence_briefs.sql`、`043_intelligence_source_jobs.sql` 和 `044_intelligence_source_publication.sql` 迁移，随 API 初始化执行；更新后同时重启 API 与空闲 worker，再使用情报台。来源快照在业务数据库中单独保存，原文读取由独立资料 worker 执行；任务继续复用已有研究执行与权限隔离机制。升级兼容早期情报表缺少发布日期字段的数据库。

**通用投研、财报分析、研报解读、产业链研究、风险复核** 集中在输入框 **研究设置 → 研究方法** 中。每次发送会保存所用方法的版本，后续修改不会改变历史研究。原“研究助手”书签自动进入研究对话；QMT 脚本生成和形态工具从 **选股 → 策略工具** 打开。

按 **Ctrl K**（Mac 使用 **⌘ K**）打开快速导航，可直接找回最近对话、项目或页面，也支持用空格组合关键词。研究页面点击示例问题只填入草稿，确认后再发送；**Enter** 发送，**Shift + Enter** 换行。

研究对话输入框支持 **/财务**、**/披露**、**/公司**、**/研报**、**/资讯**、**/行情**，例如 `/研报 五粮液`、`/资讯 601126`、`/行情 600519.SH`。输入 `/` 查看命令，用 ↑ ↓ 选择、Enter 确认、Tab 补全、Esc 关闭提示；公司可使用名称、六位代码或完整代码，省略参数时可使用当前公司。资料与行情命令直接打开已有数据；切换公司后显示当前公司，后续提问明确带上名称和代码。[快捷命令说明](docs/workbench-shortcuts.md)

## 投顾常用任务

研究侧栏的 **收评、个股分析、个股推荐理由** 直接打开对应任务设置。三者沿用情报台的真实执行进展、证据快照、历史版本与导出，点击入口只打开任务。

- **收评**：选择复盘日期，生成指数与盘面要点、主要驱动、次日观察、客户短稿与完整每日股评。未收盘时明确生成盘中草稿，缺少所选日行情时标为待补齐，不将旧日线写成当日收盘。
- **个股分析**：从A股目录选股票，填写客户问题、分析期限、持仓状态与可选成本、风险偏好。固定研究对象和时点，结合业务、财务、估值、量价、催化与风险，形成分情形的判断和行动条件。
- **个股推荐理由**：先选股票，可填写已经向客户推荐的背景。系统独立核对支持与反方证据，形成推荐逻辑、适用前提、失效条件和沟通稿。背景不作为事实证据；证据不足或不支持推荐时，提供相应的暂缓或调整说明。

结果提供 **客户短稿 / 完整稿** 切换、页面内编辑和复制，可恢复原始生成稿。页面修改用于复制，导出与历史版本保留原始生成稿；界面标注 **待投顾核对**；收评客户短稿复制为日期标题与正文，其他投顾稿复制保留 **待投顾确认** 标记。每条支持或反方判断关联本轮证据主题；引用可打开原文。历史财报允许用于个股背景研究，必须区分报告期与研究截止时间。公开PDF报告保留页码和正文快照，扫描件无可提取文字时不自动当作已核验引文。

投顾成果发布时，股票、日期、引用归属、成交金额/单位和已确认事件时间等错误在基础与严格模式下都须修复。术语、篇幅、段落和约数表达只给建议；待核验提示随成果版本保存，在稿件前展示，刷新后仍可查看，不阻止编辑和复制。严格模式额外要求分析维度及客户稿的口径、时间标注完整。[校验边界与验证说明](ADVISOR_VALIDATION.md)

投顾输入及可用本地行情在提交时冻结，本地日线按实际数据日期展示。新增迁移 `046_advisor_tasks.sql` 保存输入与行情快照；更新后重启空闲API及worker使用新任务。

收评默认采用已冻结的客户稿复核规则：成交额优先沪深两市，只与同范围的前一交易日比较；只能取得沪深京三市时明确切换整组口径，无法确认则省略金额。上涨家数使用有据的约数，单终端的精确行业涨幅、统计范围与来源差异保留在证据和完整稿。

引用的事件按原始日期、IANA时区及UTC偏移核对夏令时，再由服务端换算为北京时间并记录盘前、盘中或收盘后关系；未确认具体时刻时标明“时间待确认”。客户短稿固定包含盘面回顾、热点板块与明日观察，使用简明表达与条件式判断。发布时会拦截混用成交范围、金额换算不符、事件时区/客户稿时刻不一致和部分晦涩术语。复制收评客户短稿仅包含日期标题及正文，AI提示与研究元信息留在工作台中。规则随新任务冻结，既有版本保留原始内容与原发布契约。

## 数据与服务

**财务与披露接口** 已提供十家公司样本检查，可分别查看三表、财务指标、审计意见、披露日程、公告及 VIP 权限。点击 **检查接口与十家公司样本** 后在后台运行，支持停止和下载结果；打开面板只读取已保存状态。源记录保留原始响应、精确数值、报告期和版本，空结果、权限不足及数据异常分别说明。[第一交付包与试点结果](docs/financial-contracts-delivery.md)

**数据与服务 → 标准财务与指标计算** 可查看十家试点公司近五年财务，支持年度、累计、单季、TTM 和研究截止日；公司研究页也有对应入口。金额统一为人民币元计算、以亿元展示，空值保留原因，不补零；银行、保险、证券的通用工商业指标标为不适用。每个数字可查看源值、单位、版本和公式输入，并保存不可覆盖的计算快照。默认“当时可验证口径”要求平台在截止日前已观察到版本，今天补采的旧财报不能作为过去已取得的证据；“最新修订口径”保留这一历史局限。维护者可从此面板更新十家公司财务，停止或继续未完成分片。[标准财务交付与真实验收记录](docs/financial-series-delivery.md)

**资料库 → 原始披露** 支持上传 PDF 和导入官方原文链接，每份最多 50 MB。公司、报告期、类型、全文/摘要和披露日期可以先留待核对；识别建议不会自动确认。打开原文可添加修订全文或关联更正材料，旧版本与分类修改记录保留；阅读器按 PDF 物理页翻阅、检索和定位。公司研究页也提供对应资料入口。导入在后台进行，可停止和重试；公告权限未开通时不运行自动采集。[原始披露归档说明](docs/disclosure-archive-delivery.md)

**财务与研究证据连接**：在公司财务的“查看计算依据”中关联原文物理页、保存人工数值核对或冲突，再生成可独立打开的数字引用。项目“同业对比”提供 3–5 家公司统一口径的标准财务比较和历史保存版本。研究回合冻结财务与披露输入，修订检查可找到受影响的旧笔记；分享和 PDF 保留数字、公式、源版本和原文摘录。“文档已关联”与“数值已核对”分别展示，不自动互相升级。[第四交付包与验收记录](docs/financial-research-delivery.md)

页面显示实际行情日期和质量状态。行情可查询、探索筛选可执行、正式选股就绪是不同状态，请按当前任务提示核对所需数据。

连接异常时重新双击 `start.cmd`；仍有问题，在 **数据与服务** 中重新检查并保存诊断信息交给维护者。

更新数据时，**数据与服务** 每秒刷新总体进度、用时与股票名称、日线行情、最近30天资讯三个阶段。可查看正在读取的行情日期与分页、已处理交易日/来源数量、实际写入或新增数量，以及失败日期、来源和资讯覆盖说明；展开 **查看更新明细** 可回看最近80条记录。关闭面板后任务继续，重新打开可恢复查看；部分完成时已更新资料仍可使用，待重试与后续补齐的历史交易日会分别标明。

Tushare 行情、资讯和研究查询使用[官方 HTTP API](https://tushare.pro/document/1?doc_id=40)，直接请求 `https://api.tushare.pro`。在服务进程环境中设置 `TUSHARE_TOKEN`，或在 `config.ini` 的 `[tushare]` 下填写 `token = 你的官方token`；非空 `token` 优先，也可通过 `token_env` 指定其他环境变量。`timeout` 和 `retries` 分别控制请求超时与临时网络错误重试。未配置 token 时不会发起请求；“已配置”只表示存在凭证，实际数据权限以官方账户为准。配置后重新启动服务，使用 **数据与服务 → 更新股票名称、行情和资讯**，或运行 `scripts/update_tushare_data.ps1` 同步。

## 更新本地版本

维护者拉取最新代码后，在 `apps/web` 运行 `npm run build`，然后重新启动服务；只拉取源码不会更新已有的 `dist` 界面。研究任务正在运行时可以用 `scripts/reload_api.ps1` 只更新网页/API，保留后台 worker；后台代码在任务完成后随下一次完整启动更新。模型选择、助手启动、对话附件、回答版本和公开分享来源分别使用 `031_research_models.sql`、`032_research_assistant_launches.sql`、`033_research_attachments.sql`、`036_research_answer_actions.sql`、`037_research_share_sources.sql` 迁移，由应用初始化执行；更新前请备份数据库。文件读写依赖包含 `openpyxl`、`python-docx` 和 `python-pptx`，按 `requirements.lock` 安装。

公开分享服务源码在 `sites/research-share`，由 Sites 托管，快照独立保存在 R2。本地读取 `runtime/share-service.json` 中的 `public_url` 和 `api_key`，或环境变量 `LLMR_SHARE_SERVICE_URL`、`LLMR_SHARE_SERVICE_KEY`；云端仅配置对应的 `SHARE_WRITE_KEY` secret。密钥不会进入前端、源码仓库或分享快照。分享没有依赖本地电脑在线，停止本地服务不会使已发布快照消失。需要完整原格式文档时仍使用本地文件交付；公开快照仅嵌入其所链接的 Markdown/文本报告与原文摘录。

## 模型与助手配置（维护者）

[配置示例](config.example.ini) 中的 `[research_models]` 由服务端控制账户和模型范围：

- `account_tier = free`：可用值为 `free`、`paid`、`enterprise`；环境变量 `LLMR_RESEARCH_ACCOUNT_TIER` 优先。此设置不会授予供应商账户原本没有的权限。
- `allowed_models =`：可选的逗号分隔模型白名单；留空表示不额外限制受支持的模型目录。环境变量为 `LLMR_RESEARCH_ALLOWED_MODELS`。白名单不能绕过 Free 账户限制。
- `reasoning_efforts_json = {}`：维护者核验过的模型档位映射，例如 `{"gpt-6-luna":["low","medium","high"]}`；环境变量为 `LLMR_RESEARCH_MODEL_EFFORTS_JSON`。未覆盖的模型使用内置档位。

模型目录结合以上策略与供应商 `/v1/models` 返回值决定可用性。未确认支持的备选模型保持禁用；发现服务暂不可达时，仅保留已显式配置且符合账户策略的默认模型，认证失败则全部禁用。`[app].reasoning_effort` 是新会话的默认档位；执行时使用当轮保存的选择，普通／深入研究的时限预算不会再把它强制映射为 `high`／`max`。

三个即时助手要求 `[research].web_search = live`（或 `LLMR_RESEARCH_WEB_SEARCH=live`），并需要模型服务实际支持联网检索；原生搜索还需在对应 `[model_providers.<名称>]` 中按实际能力启用 `supports_standalone_web_search`。变更供应商后应验证真实搜索和打开来源页面；检索失败须在答复中说明，不能用模型记忆补齐“今日资讯”。

即时启动在同一事务中保存请求、对话和首轮消息，再进入后台队列。首轮冻结北京时间、研究截止日、模型、推理档位及完整技能快照和哈希。网络重试使用原 `request_id`，重用同一对话和任务；已完成、失败或停止的任务不会因重放请求自动重跑。排队前中断可用相同请求恢复，跨日恢复仍保留原截止时间。

后续扩展由维护者在 `apps/api/app/research_assistants.py` 的 `BUILTINS` 注册 `AssistantDefinition`，并在 `apps/api/app/skills/<skill>/SKILL.md` 提供方法、来源要求和输出规范。即时助手配置 `launch_mode="immediate"`、按钮文案和 `default_prompt`（支持 `{as_of_date}`），更新 `revision`，沿用统一启动接口；现有客户端按目录元数据呈现。当前即时任务仅支持无参数启动，`input_schema` 是扩展契约；增加参数时需同步实现服务端校验、请求哈希与界面输入。上线前覆盖目录、幂等重试、冻结快照和失败恢复测试，用户端继续保持点击即用。

## 维护资料

备份使用 `scripts/backup.py <新备份目录>`，可加 `--include-source` 复制行情和本地研报源。新版备份包含身份库、全部个人工作区数据库、附件、原件、研究成果及会话状态，并保存完整文件校验清单；备份期间若数据库或文件发生变化会失败，请在任务和资料更新空闲时重试。恢复使用 `scripts/restore.py <备份目录> <新恢复目录>`，校验通过后按生成的 `storage-environment.json` 配置各存储根目录再启动服务；恢复不会覆盖现有目录，账户保留但需要重新登录。旧版备份仍可恢复，新版功能不能补回旧备份未保存的资料。
