# 选股结果工作区

侧栏“研究”中的“选股对话”显示对话、方案版本和筛选批次。桌面宽度大于 1100px 时，已有筛选批次的对话自动展开结果区。左侧约 38% 显示对话与输入框，右侧约 62% 显示方案、候选名单和逐股判断依据。自动展开时焦点留在原位。用户主动关闭后，可用页头按钮重新打开。

中间分隔条支持拖动和键盘左右方向键调整比例（对话占 30%–55%，保留两侧最小可读宽度）；Home/End 跳到边界，双击恢复 38%/62%。比例随当前工作区保存，切换任务及刷新后继续使用。

结果默认展示符合项，也可搜索、翻页及查看不符合或数据不足的判断。点击“查看依据”定位到所选股票的完整依据，可用“上一只”“下一只”切换，并用“返回名单”回到点击位置。输入区已有草稿时，追问会另存为带批次引用的独立草稿，可通过“返回原选股草稿”恢复原要求。

方案和结果共用顶部批次选择框，显示数据截止日期和方案版本。历史批次的方案为当时实际采用的只读规则。用“编辑当前方案”打开当前规则，再用“返回批次方案”继续核对历史。逐股判断、导出、追问引用、继续研究以及结果区的“保存为方案”均使用当前查看的批次。

可以逐股或勾选多只加入观察池，沿用手动观察及已有记录复用接口；既有筛选批次的跟踪记录不变。继续研究会打开独立研究草稿，携带股票、筛选批次引用、截止日期和版本，明确区分批次时点和后续信息；用户发送前不运行模型。

从个股研究点「返回筛选结果」，工作台会恢复原批次、结果筛选和页码，并打开该股的判断依据。同一浏览器会话刷新后也可恢复。提交个股研究时，服务端将该股在原批次的已保存判断连同截止日与方案版本固定为引用。

1100px 及以下使用结果抽屉，用户从“查看名单/查看进度”进入，保留焦点限制、Escape 关闭和原草稿恢复。结果抽屉的标题、关闭按钮与方案/结果切换保持可见。

## 条件组合与对话选股的运行记录

- 两个入口都在提交时固定版本和截止日。历史中的版本号对条件组合指策略版本，对话选股则指任务修订号。修改当前方案后，已提交批次仍使用当时的版本。
- 同一次提交丢失响应时，沿用原请求标识或原回合授权即可找回原批次。取消走同一个任务接口，历史页显示对应的取消状态。条件组合的任务重试会用原快照生成新批次，对话选股通过当前方案和该回合的授权发起执行。
- 历史按批次创建时间倒序展示，同一时间按批次编号倒序。先合并两类记录，再取对应数量。
