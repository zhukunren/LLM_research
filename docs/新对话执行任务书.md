# 新对话执行任务书

> 历史任务书，2026-09-28 起不再作为新一轮实施入口。请使用 [Luna6 执行任务书](Luna6执行任务书.md) 和 [对话式股票筛选实施计划](对话式股票筛选实施计划_Luna6.md)。下文保留首期历史要求，其中“仅封闭 JSON、不允许模型生成代码”和“应用尚未创建”等描述不代表当前目标。

这份任务书用于直接启动平台实施。完整设计与验收以同目录的 [LLM投研工作平台实施计划](./LLM投研工作平台实施计划.md) 为准。

## 可直接复制到新对话的内容

```text
请在 D:\项目\LLM_research 中实际实现 LLM 投研工作平台。

先阅读：
1. D:\项目\LLM_research\docs\LLM投研工作平台实施计划.md
2. 工作区内当前存在的 AGENTS.md、README、docs/execution-status.md、docs/decisions.md（如果存在）。

请执行实施计划，不要再只输出一份计划。按 M0–M10 顺序持续推进，完成可以在当前环境中验证的首期功能。若已存在阶段成果，先检查并复用，不要重新搭建或覆盖。

必须有六个一级菜单：观察池、资讯库、技术指标库、形态库、研报库、筛选设置。研报库必须独立，不能放回资讯库的子页。

核心要求：
- 资讯库、技术指标库、研报库都能直接对话制定条件，提供可编辑的结构化草稿、校验、试运行或明确的依赖阻断、保存和重载。
- 资讯目前不接入真实数据，预留 Tushare。未接入时仍能对话保存条件；涉及它的正式运行明确阻断，不能以假资讯填充。
- 形态库必须真正支持手绘走势、手绘蜡烛和上传截图提取；能校正、保存、重载、匹配真实行情。只有上传按钮或图片描述不算完成。
- 筛选设置可以组合各库已保存条件，支持 AND/OR/NOT、分组、参数覆写、评分和 TopN；条件和策略均固定版本。
- 观察池加载策略执行，显示实际数值、原文引用、形态对照和未完成原因；人工观察分组独立保存。

默认按计划采用 React + TypeScript + Vite、FastAPI、SQLite、DuckDB/Parquet、独立后台 worker。小幅技术调整记录理由后自行执行，不必为常规可逆选择反复询问。

现有资源必须保护并复用：
- data/stock_data/stock_daily.parquet：只读检查时约 624.4 MB、16,933,080 行、5,562 个证券代码，日期截至 2026-09-14。
- data/research_report/：12 份 PDF，文件名日期晚于当前行情水位，且含港股和韩国标的。
- config.ini：已有模型和 Tushare 相关配置结构。只在需要时安全读取，不能输出密钥、提交到 Git 或传给前端。不能假定该文件全部字段就是平台配置。

关键正确性：
- 核验行情价格复权口径和量额单位；未知时标记、限制相关正式执行，不能猜测。
- 截止时间、首次可用时间、交易日、证券市场、历史窗口要明确；后来的研报不能进入 2026-09-14 的严格历史筛选。
- 使用 true/false/unknown；缺失和运行异常不能静默变成“不命中”。
- LLM 生成受约束 JSON 规则，确定性引擎执行，不执行模型生成的任意代码或 SQL。
- 规则、数据快照、派生证据和算法有版本，修改条件不能改变历史策略或运行。
- 演示、测试夹具、探索模式与真实正式运行明确分开；不伪造当前全市场结果。

实施方式：
1. 先检查实际文件和数据，再搭建最小可启动应用。
2. 优先打通数据查询与规则引擎，再接对话、研报、资讯条件、形态和组合工作流。
3. 创建并持续更新 docs/execution-status.md、docs/decisions.md、docs/data-profile.md；记录阶段、文件、验证命令、结果、待办和下一步。
4. 做必要的规则/数据边界测试和端到端验收；截图识别需有真实评测，不能以 mock 宣称完成。
5. 提供 Windows 启动脚本、README、依赖锁文件、迁移、配置样例、备份恢复和操作说明。
6. 连续推进已授权的实施工作。遇到缺失模型权限、数据来源等真实外部阻断时，先完成不依赖它的工作，保留明确待验收项，最后集中报告。

交付时说明本地启动方式、六菜单完成情况、实际运行和测试证据、形态识别质量、数据水位及剩余外部依赖。请开始执行。
```

## 跨对话续做时使用

```text
请继续 D:\项目\LLM_research 的 LLM 投研工作平台实施。
先阅读 docs/LLM投研工作平台实施计划.md 和 docs/execution-status.md，检查已有代码与实际测试结果，从第一个未完成阶段继续。
保留六菜单、三个库对话建条件、手绘与截图形态识别、组合策略与观察池等全部首期要求。不要重新初始化项目，也不要把未完成的功能移到远期来宣称首期完成。
推进后更新执行状态、验证记录和下一步任务。
```

## 说明

当前交付的是实施文档；上述启动脚本、应用和 execution-status 等文件应在实际实施阶段生成。任务书中的行情/研报统计以 2026-09-25 检查为基准，执行时若源文件变化，需要重新检查并更新状态。
