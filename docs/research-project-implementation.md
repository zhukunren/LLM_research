将研究主题、公司、对话、证据、计算、笔记与观察串成可持续的研究过程。沿用 React/FastAPI、唯一 Codex 研究内核、MCP 工具、Python、DuckDB/Parquet、本地 SQLite 和现有任务恢复机制。资料库的阅读与条件创建入口、冻结筛选运行和观察批次继续保留。

## 第一阶段：研究中心

- 持久研究项目：目标、关联公司、项目归档与恢复。
- 已有对话归入项目，从项目创建新研究并继续原对话。
- 同一项目聚合跨对话成果；保存助手答复为笔记，保留不可变原消息的出处。
- 笔记关联公司、记录验证事项和失效条件，人工维护观点状态。
- 每次编辑保存不可更新的笔记历史快照，可查看原判断、状态和验证事项；当前版本使用并发修订检查。
