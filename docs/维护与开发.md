# 维护与开发

## 本地安装与启动

准备 Python 3.12 和 Node.js。从项目根目录运行 `.\scripts\bootstrap.ps1` 安装后端和前端依赖。首次配置时，把 [config.example.ini](../config.example.ini) 复制为根目录的 `config.ini`，按需填写模型和 Tushare 凭证。

在 `apps/web` 运行 `npm run build`，再回到根目录双击 `start.cmd` 启动。处理中的后台任务仍需完成时，可用 [reload_api.ps1](../scripts/reload_api.ps1) 单独重启网页和 API。

## 代码入口

- [前端会话工作区](../apps/web/src/components/conversation/ConversationWorkspace.tsx) 管理共用的草稿、消息和回合。研究范围和成果动作由 [研究会话模块](../apps/web/src/components/conversation/useResearchConversation.ts) 管理。选股有独立的 [提交模块](../apps/web/src/components/conversation/useScreeningExecution.ts) 和 [结果模块](../apps/web/src/components/conversation/useScreeningRunResults.ts)。
- [后端启动入口](../apps/api/app/main.py) 装配鉴权、错误处理、业务路由和网页。查看接口实现时，按 [系统设置](../apps/api/app/system_api.py)、[行情和指标](../apps/api/app/market_api.py)、[形态](../apps/api/app/pattern_api.py)、[研报库](../apps/api/app/document_api.py)、[研报评估](../apps/api/app/report_evaluation_api.py)、[观察分组](../apps/api/app/watchlist_api.py) 或 [后台任务](../apps/api/app/jobs_api.py) 查找对应模块。
- 已保存条件、组合运行和对话选股的入口分别在 [条件接口](../apps/api/app/filter_api.py)、[组合筛选接口](../apps/api/app/screening_strategy_api.py) 和 [对话筛选接口](../apps/api/app/screening_api.py)。两类选股记录由 [筛选历史](../apps/api/app/screening_history.py) 汇总。版本及重试规则见 [选股结果工作区](research-results-workspace.md#条件组合与对话选股的运行记录)。
- [后台 worker](../apps/api/app/worker.py) 从队列领取任务并分派给业务模块。组合筛选、对话选股、研报评估和研究扫描分别由 [组合筛选执行](../apps/api/app/screening_strategy_execution.py)、[对话选股服务](../apps/api/app/screening_service.py)、[研报评估服务](../apps/api/app/report_evaluation.py) 和 [研究扫描服务](../apps/api/app/research_scan_service.py) 执行。

## 数据与备份

配置 Tushare 后，可在工作台的「数据与服务」发起更新，也可运行 `.\scripts\update_tushare_data.ps1` 从命令行更新。界面会显示数据实际更新到哪一天。

备份使用 `scripts/backup.py <新备份目录>`，恢复使用 `scripts/restore.py <备份目录> <新恢复目录>`。`--include-source` 可将行情和本地研报也纳入备份。存储目录配置见 [可变存储](phase1-storage-and-sandbox.md)，备份选择见 [备份保留](backup-retention.md)。

## 本地测试

从根目录运行 `.\scripts\test.ps1` 可运行后端测试。在 `apps/web` 运行 `npm test` 可运行前端测试。指定单个测试文件的方法及测试文件的保存位置见 [测试临时文件与失败现场](test-artifacts.md)。
