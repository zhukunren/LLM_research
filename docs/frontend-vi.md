# 投研工作台前端 VI 与视觉规范

工作台用白色承载正文和表格，用浅灰蓝划分导航与工作区。证券蓝 `#004A99` 用于主操作、链接和当前选中项。涨跌、资料核对和操作结果都有各自的文字标签。对客卡片沿用现有七套刊头风格，编辑工作台使用统一界面色。

## 品牌标识

- 浅底使用蓝色全标，深色刊头使用白色全标。桌面侧栏全标建议宽 `134 px`，紧凑栏图形标建议 `28 px`。全标和图形标均等比缩放。
- 标识周围留出至少 `8 px` 的界面空间，作为此工作台的排版间距。营业部及工作台名称单独排在标识下方，使用 `12/18 px` 辅助文字。
- 识别度优先。图面要有足够的实底留白承载标识，底图上的亮斑和复杂纹理避开刊头标题、标识和日期。 [项目标识文件与来源](../apps/web/public/brand/SOURCE.md)

- A 股涨幅用红色和 `+`，跌幅用绿色和 `−`。平盘显示 `0.00%`，缺数显示 `—` 并给出缺数原因。筛选结果使用「符合」「不符合」「资料不足」，其中「不符合」用中性标签。
- 成功、待核对和失败分别使用绿、琥珀和红的浅底标签，配文字或图标。信息提示使用主蓝与浅蓝底。截图和导出也保留文字状态。
- 普通文字以 `4.5:1`、可识别控件状态和关键图形以 `3:1` 为最低对比门槛。此组颜色中，主按钮白字 **8.61:1**，辅助文字与工作区底 **5.10:1**，涨幅与跌幅在各自浅底上分别 **5.59:1** 和 **6.30:1**，控件边框与白底 **3.41:1**。 [W3C 文字对比](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html) · [W3C 非文字对比](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html)

## 字体与数据

界面字体用 `system-ui, "PingFang SC", "Microsoft YaHei UI", "Noto Sans CJK SC", sans-serif`。研究正文保留舒展的行高，列表用稍小但对比更高的文字。以下尺寸为字号与行高，单位为 `px`。

- **页面标题** `24/34`，字重 `700`。同一页面的标题随工具栏和内容区排版选定一个主要位置。
- **区块标题** `18/26`，字重 `600`。紧凑面板的标题用 `16/24`。
- **阅读正文** `15/26`，字重 `400`。研究答复和长文阅读区建议宽 `760–820 px`。
- **界面与表格** 界面正文 `14/22`，表格及字段标签 `13/20`，辅助信息 `12/18`。代码用当前等宽字体。金额、比率、代码和时间使用 `font-variant-numeric: tabular-nums`，可对照的数字列右对齐。
- **关键数字** `24/32`，字重 `600`。单位紧跟数字或放在表头。图表横轴标明日期范围，纵轴标明单位，区分数据时点、来源和复权口径。多条曲线同时使用线型或标记与直接标签。

## 页面布局

采用 `4 px` 间距基准。标签到控件用 `8 px`，面板内边距常用 `16` 或 `20 px`，区块间用 `24 px`。面板圆角 `12 px`、控件圆角 `10 px`。普通面板主要靠边框和留白分层，弹窗和浮层用现有遮罩及阴影。

- **常规桌面**（`≥1280 px`）左侧栏 `240 px`，工作区顶栏 `52 px`。内容边距 `28 px`，主要分栏间距 `24 px`。登录条和工作区一起占满窗口，列表、长表单和预览在各自区域滚动。
- **紧凑桌面**（`901–1279 px`）内容边距 `20 px`，主要分栏间距 `16 px`。优先给主要阅读区留宽度，证据能从右侧打开，表格横向滚动限制在表格区。
- **窄屏**（`≤900 px`）主导航收入抽屉。`≤850 px` 的对客工作台使用「编辑／预览」切换。`≤600 px` 时套图放在预览下方，常用触控区域至少 `44×44 px`。

四个主页面沿用同一套工具栏、标题和控件高度。

- **研究对话**集中展示问题、答复与后续输入。数据时点和引用贴近相应的答复。来源多时从侧边打开，关闭后回到触发位置。
- **选股与观察池**先显示筛选范围、时间和结果，再展示名单。表头与数字列保持对齐，个股依据紧贴当前选中的证券。按排序键、代码和日期还原用户看到的结果。
- **资料库**左看目录、右读正文或原页。打开披露后将阅读区带入视野，关闭后返回原条目。PDF 页码、缩放与资料动作保持同一工具栏。
- **对客编辑**左侧放模板字段，中间放图片／文案预览，右侧放底图，三栏间距 `16 px`。常规桌面给编辑区至少 `290 px`，套图栏建议 `152 px`，预览占剩余宽度。复制与下载固定在预览区底部，长图、长文案、证据详情及套图各自在对应区域滚动。

## 组件与状态

- **按钮** 常用高度 `36 px`，紧凑工具 `30 px`。一个操作区域只突出一个实底蓝按钮。次操作用白底描边，轻操作用文字或图标。悬停用深浅变化，按下用深蓝，键盘焦点用 `2 px` 亮蓝描边、外偏移 `2 px`。
- **输入框** 标签留在输入框外，填完仍可识别字段。错误放在相关字段下方，并说明修正项。日期、代码、价格和仓位有明确的输入格式或单位。
- **列表、表格与标签** 普通单行高 `44 px`，紧凑单行高 `36 px`。双行证券名称和代码按内容增高。长标题最多两行，表格中的核心判断和单位完整显示。行扫描主要靠留白与横向分隔线。选中状态可通过浅蓝底、深蓝文字和选中标记辨认。
- **图标与响应** 使用现有 Lucide 图标，普通控件图标 `16–18 px`。仅有图标的按钮提供可读名称。交互过渡保持在 `150 ms` 左右，并响应系统减少动态效果设置。
- **加载、空白与失败** 加载时预留结果区尺寸。暂无数据时写明原因和下一步。失败状态保留可读结果、已填字段和可用操作，把重试放在对应内容旁。
- **抽屉与导出** 打开时将焦点移到操作区域，Esc 关闭后返回触发位置。导出区固定位置，异步预览和状态提示在操作区上方更新。草稿、成品、正在发送和发送失败分别使用明确的文字。

## 对客卡片

时点卡片、开盘计划、调仓建议共用 `1080 px` 宽的版式。刊头承载品牌、标题和时点，正文随内容增高，风险提示与投顾落款在底部保持清晰、完整。每套底图保有统一色调和排版，时点画面按日期任务选取，开盘计划与调仓建议各用同色系的独立画面。

七套主题分别是锦绣江岸、冰蓝科技、曜金几何、星穹银紫、朱砂丹霞、远洋航线和铂银建筑。套图应用于交付图片和相关缩略图。图片与文案来自同一份编辑内容，下载和全屏预览使用当前已渲染版本，日期、风险提示和投顾落款完整呈现。 [卡片版式与发布约定](client-service.md) · [渲染器与各主题颜色](../apps/api/app/client_service_images.py)

## 实施和验收

工作台从共享变量读取颜色、字号、间距和控件尺寸。共享组件定义交互状态，页面样式处理各自的分栏和滚动。公开分享和财报复核原型沿用同一组颜色与阅读字号。 [项目样式变量](../apps/web/src/tokens.css) · [控件状态](../apps/web/src/control-states.css) · [表格和工具栏](../apps/web/src/data-surfaces.css)

- 在 Edge 的 `1440×900` 和 `1280×720` 检查侧栏、顶栏、分栏和主要动作。三类客户卡片的复制与下载在首屏同一高度。登录后仍能点到底部工具。用一条长标题和一张长卡检验滚动。
- 在 `390×844` 检查导航抽屉、编辑／预览切换和导出。用键盘检查焦点、搜索跳转、PDF 定位和关闭后返回。
- 覆盖正常、加载、暂无数据、资料不足和失败状态。核对红涨绿跌与状态标签是否同时提供文字信息，检查长公司名、负数、百分比、日期和风险落款。

### 2026-11-21 桌面验收记录

在 Edge 用本地样例数据和模拟登录走查了 55 个页面及关键状态。`1280×720` 和 `1440×900` 各保存 55 张截图。这轮走查的整页横向溢出、浏览器脚本异常和 HTTP 5xx 均为 0。

- `1280×720` 的筛选结果首屏可见名单首行，筛选结果与条件组合的搜索框使用同一套边框和焦点样式。查看个股依据后可回到原名单行。
- 两个尺寸下三类对客卡片的复制、下载位置对齐。从研究答复带入摘录前后，下载位置保持一致。下载的图片与预览一致。
- 原始披露打开后定位到 PDF 阅读区，关闭后焦点回到触发条目。快捷搜索可打开六个对客服务子页并恢复草稿。公开分享覆盖正常阅读、来源抽屉及无效链接提示。
