# 标准财务与指标计算交付记录

交付日期：2026-10-20。第三交付包使用当前可用的普通 `income`、`balancesheet`、`cashflow`、`fina_indicator` 接口，建立十家公司财务序列、不可覆盖的标准事实及可复算指标。未调用 VIP 或公告采集接口。

## 使用入口与真实覆盖

打开“数据与服务 → 标准财务与指标计算”，或公司研究页的同名区域。选择公司、截止日、年度/本年累计/单季/TTM、数据版本口径和指标；点击“查看计算依据”可逐个核对输入源值、单位、公告日期、首次观察时间与报表类型。“保存本次计算”冻结请求、公式版本、输入事实和结果；来源变化时要求重新读取后再保存。

试点沿用贵州茅台、美的集团、宁德时代、比亚迪、中芯国际、三一重工、万科 A、招商银行、中国平安、中信证券。当前主展示范围为 2021–2025 五个完整年度及 2026 年期间，额外保存 2020 年比较基期，用于同比与 TTM。

截至 2026-10-20，十家公司均取得 2020Q1–2026Q2 共 26 个季度的源记录。取得某期记录不代表所有字段完整，页面逐指标给出覆盖与缺失原因。2026Q3 的四类普通接口补查均为空，仅表述为“未取得该期源记录”，不推断公司没有披露。

本次运行 `2140ef4a-27bd-432b-8568-dcaa54156ba6` 成功执行 380 个请求分片，其中 310 个取得记录、70 个返回空结果；保存 1,902 个源记录版本。标准事实共 15,258 个，其中源字段非空 13,859 个、源字段空值 1,399 个。版本与事实数量包含相同报告期的不同源记录，不是独立报告数量。

## 单位、口径与缺失处理

金额按已验证的字段合同统一为 CNY 元，使用 Decimal 和十进制字符串保存与计算；页面转换为亿元展示，依据区继续显示精确元值。比率为百分比或倍数，不与金额混算。非 CNY 记录缺少核验汇率时返回待换算原因，不猜测汇率。接口字段含义沿用[利润表](https://tushare.pro/document/2?doc_id=33)、[资产负债表](https://tushare.pro/document/2?doc_id=36)、[现金流量表](https://tushare.pro/document/2?doc_id=44)、[财务指标](https://tushare.pro/document/2?doc_id=79)的合同。

三表计算使用 `report_type=1` 的合并报表。调整比较表与调整前表分别保存；母公司和合并报表不拼接。单位、币种、公司类型或字段合同冲突时阻止混算。发现较新的调整比较值与历史主表不同，相关派生值返回“重述口径待复核”，不能靠自动选最新一条消除差异。

支持 31 个基础字段与 8 个派生指标：计算毛利率、合并净利率、经营现金流/合并净利润、资产负债率、经营现金流减购建长期资产现金，以及营业收入、归母净利润和经营现金流同比。银行、保险、证券保留原始三表；工商业专属字段和指标明确不适用，未实现其行业专属分析模板。

空字段、未返回字段、缺报告期、版本冲突、无法确认历史可得性、分母为零和行业不适用分别保留状态及中文原因。不补零、不前值填充、不用别的期间替代。负数保留；同比基期非正时不给普通百分比，改列绝对变化和扭亏、转亏、亏损收窄等分类。

## 单季、TTM 与勾稽

- 流量单季：一季度取本年累计，二至四季度取本年累计减同年上一季度累计。
- 流量 TTM：上年全年 + 本年累计 − 上年同期累计；十二月直接取全年。
- 余额字段：始终是对应期末余额，不相加、不差分；现金流表期初现金单独标为期初。
- 派生比率：先取得相应单季或 TTM 流量，再计算比率。供应商原始 ROE 等比率不做累计差分或 TTM 相加，返回不支持该口径。
- 经营现金流减购建长期资产现金是明确命名的现金代理指标，不等同于完整企业自由现金流。

计算检查资产等于负债加权益、合并净利润归属和现金期初至期末变动，使用 1 元容差。差异只用于提示复核，不改写源数字，也不证明已核验原始财报。

## 修订、历史截止日与快照

保留原始响应字节及哈希、每个源记录内容版本、每次观察时间和采集尝试；新结果不覆盖旧版本。仅 `update_flag` 不同、数值等内容相同的行视为等价，仍保留全部来源；同日不同内容且无法确定先后的版本返回冲突。

“当时可验证口径”（`mode=as_of`）同时要求公告日期和平台首次观察时间不晚于截止日。“最新修订口径”（`mode=latest`）按供应商公告日期过滤当前已取得版本，可能包含后来修订。今天补采的数据不能证明在历史日期已可获得；本次 2026-10-19 的严格历史查询全部无可用数值，这是保留证据边界的预期结果。

每次计算返回公式 `financial-series-v1`、标准化版本 `financial-facts-v1`、确定性计算标识、依赖期间与输入事实 ID。保存时重新计算并核对页面的预期标识；不一致返回 409。快照不可更新、删除，之后来源改变仍能读取原结果。当前溯源到 Tushare 原始响应，尚未逐字段连接并核验第二交付包中的原始 PDF；该状态明确保留。

## 采集与运行

维护者点击“更新十家公司财务”启动独立后台任务，支持停止、故障恢复和继续未完成分片。普通用户可保存计算，只读用户只能读取。数据、原始响应与快照均在当前工作空间，沿用现有身份与隔离机制。

三表日期范围按公告时间拆分，财务指标按报告期拆分。达到行数保护上限时继续拆日期；最小分片仍达到上限则标为不完整。完成范围请求后按缺失报告期补查一次，空响应及排除的非目标记录均留下证据。权限或网络失败保留尝试并中止该接口的后续请求，其他接口继续；重试不重新覆盖成功分片。取消或失去任务租约后不发布新事实。

实现文件为 `financial_facts.py`、`financial_sync.py`、`financial_metrics.py`，API 扩展在 `financial_data_api.py`；迁移为 `045_financial_series.sql`，新增分片、尝试、来源观察、标准事实和计算快照。使用 `financial-sync-v1` 工作协议，需同时更新 API 和空闲 worker。备份包含数据库、`financial-sources/` 原始响应及 `financial-series/` 验收文件。

主要 API 均带 `/api/v1` 前缀：

- `GET /financial-data/series-status`、`GET /financial-data/metrics`：采集覆盖和指标目录。
- `GET /companies/{stock_code}/financials`：参数 `as_of`、`start_year`、`basis`、`mode`、`metrics`；接口默认 `mode=latest`，历史研究应显式指定 `as_of` 模式，页面默认严格模式。
- `POST /financial-data/calculations?expected_id=...`、`GET /financial-data/calculations/{id}`：冻结和读取计算。
- `GET /financial-facts/{id}/provenance`：精确源值、源记录与观察证据。
- `POST /maintenance/financial-sync`、`GET /financial-data/syncs/{id}`、`POST /maintenance/financial-sync/{id}/retry`：采集及恢复。
