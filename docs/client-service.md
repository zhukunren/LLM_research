# 对客服务与时点卡

入口为研究、选股侧栏的“更多工具 → 对客服务”，直达地址 `#/tools/client-service`。它根据《锦绣成长·11月16日内容样例包》的对客时间表提供六类卡片：盘前简报 08:45、开盘观察 09:45、关键时点 10:30、午间观察 11:35、尾盘观察 14:30、收盘总结 15:30。时间均为北京时间，可以分别调整、启停，并选择生成的星期。

样例中的市场数字、买卖安排、仓位和阈值没有作为新卡片的行情或交易结论。晨会、次日内部交易计划、周报和月报不属于此次六个对客时点。

## 编辑与保存

市场状态由 Codex 实时检索公开资料，保留实际打开的来源、数据时点和信息截止时间；无法核实的指标显示“未核实”。盘前区分上一交易日收盘和隔夜行情，历史盘中卡不能用之后的行情补造原时点。

侧边可编辑服务名称、卡片标题、今日判断、行动安排、观察重点、服务说明、投顾姓名、执业编号和风险提示。文字变化后同步生成预览，下载 PNG 使用当前已完成的预览，避免下载旧版本。采集市场状态不会修改上述用户栏目。

“保存本次卡片”保存当前日期、时点的内容；“保存为默认模板”让以后该时点的卡片沿用当前内容。修改生成时间、星期、启用状态后，点击“保存模板和计划”。未保存的编辑草稿随当前工作区标签保存在本机当前登录会话中。

在服务日期中选择历史日期可查看、修改和下载已有卡片；“重新采集市场状态”仅重新检索该卡原有的信息截止时点，保留已保存的用户文案，即使后来修改默认计划也不会改变历史卡的截止时间。未来日期或尚未到达的当日时点只可提前编辑模板、预览图片，到对应时刻后才能采集市场事实，避免提前手动采集占用当天的自动时点。09:45 和午间卡都会生成草稿，由用户决定是否使用。

## 每日执行

调度器运行在已有 `llmr-worker` 内，每 20 秒检查一次已启用计划。页面关闭不会停止任务。每日期、时点只有一张卡；定时请求标识固定，重复检查、API 重试和重启恢复均复用同一任务。预留卡片后尚未来得及入队的任务可以恢复入队。

调度只在计划时刻后的 15 分钟窗口内自动触发，停机错过的盘中时点不会事后自动编造行情。已经入队的任务继续遵守冻结的截止时间。默认计划为周一至周五；这不是自动识别法定休市日的交易日历，休市事实由采集结果说明，也可调整生成星期或关闭相应时点。

Codex 使用现有研究队列、模型选择策略与原生联网能力。只传入标准时点任务和冻结日期，不把用户的判断、行动、投顾身份或其他模板文案发送给模型。市场来源必须同时满足实际搜索、实际打开和时点校验；未通过的结果显示采集失败或数据待核实。服务只制作卡片，不向客户群或其他渠道自动发送。

采集完成和保存内容后，同一图片引擎会生成服务端 PNG，存放在各自工作空间的 `artifact_root/client-service/<card-id>.png`。预览、历史下载和自动生成使用同一渲染器，1080 像素宽，图片高度按文字自动增长。文件通过临时文件加原子替换写入。中文字体使用 Noto Sans CJK，也可由 `LLMR_CLIENT_CARD_FONT` 指定字体路径。

## API

所有接口均沿用本站认证和个人工作区隔离。

| 接口 | 用途 |
| --- | --- |
| `GET /api/v1/client-service/settings` | 读取模板与计划 |
| `PUT /api/v1/client-service/settings` | 按 revision 保存模板与计划 |
| `GET /api/v1/client-service/cards?date=YYYY-MM-DD` | 读取当日各时点卡片 |
| `POST /api/v1/client-service/cards` | 按 request_id 幂等创建或重新采集 |
| `GET /api/v1/client-service/cards/{id}` | 读取采集状态、市场资料和用户内容 |
| `PUT /api/v1/client-service/cards/{id}` | 按 revision 保存用户内容，不接受 market 覆盖 |
| `POST /api/v1/client-service/preview` | 按当前编辑内容返回 PNG 预览，不保存或调用模型 |
| `GET /api/v1/client-service/cards/{id}/image.png` | 下载已保存卡片的图片 |

设置和卡片均有版本检查；发生并发修改时返回 409，用户草稿继续保留。市场采集结果和手工文案分开存储，后台完成不会覆盖手工编辑。专用采集会话不进入普通研究侧栏历史，也不自动生成研究 PDF。

## 图片模型底图

按用户最新要求，图片模型制作底图后置；当前可用的蓝白标准版式由排版引擎绘制。已准备的生成提示词保存在 `output/imagegen/client-service-template-prompt.txt`，尚未产生图片模型输出。此前使用已配置中转站及用户提供的密钥，均被接口以 403“Image generation is not enabled for this group”拒绝。

底图生成成功后，将选定图片复制到 `apps/web/public/client-service/market-card-background.png`，同一渲染器即可使用。文字继续单独绘制，便于编辑、核对中文和实时更新；不需要逐次调用图片模型重新生成文字。
