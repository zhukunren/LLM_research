# 对客服务与时点卡

侧栏「服务」提供时点卡片、开盘计划、调仓建议、生成计划与模板、群机器人和发送记录。时点卡片直达地址为 `#/tools/client-service`。其他页面可通过同一路径的 `?view=opening-plan`、`?view=suggestions`、`?view=templates`、`?view=robots`、`?view=deliveries` 打开。切换回研究时恢复之前的页面。时点卡片按《锦绣成长·11月16日内容样例包》的时间表提供盘前简报 08:45、开盘观察 09:45、关键时点 10:30、午间观察 11:35、尾盘观察 14:30、收盘总结 15:30。时间均为北京时间，可以分别调整、启停和选择生成的星期。

从侧栏「生成计划与模板」设置自动生成的星期、时点和默认文案。保存采用设置版本检查，后续卡片使用新模板，已有卡片保留原内容。时点卡片页显示当前自动生成状态和时区。

「开盘计划」可从 `#/tools/client-service?view=opening-plan` 打开。按日期编辑开盘判断、盘前速览、观察方向和风控等段落。「保存为默认模板」保留当前文案与套图供尚未保存的日期使用，「保存本次卡片」单独保存当天的内容。AI 采集最多使用计划日北京时间 09:15 前发布的资料，并用实际交易日标记行情。采集结果补入留空且尚未编辑的段落，已有段落可在采集详情中逐段选用。按日保存后仍可核对本次采集的原文。右侧可切换图片和文案，点击图片中的字段可编辑。复制文案和下载 PNG 均包含计划日期、投顾落款和固定 R4 风险提示，未保存的内容带草稿标记。

「调仓建议」按股票代码获取最新可核对报价，显示行情时点和来源。可手动改价，或点「取最新价」重新获取。在生成档位下拉框选即时或深度。即时请求 GPT-6.2 Astra Low 和 Fast，深度请求 GPT-6.2 Sol Max。AI 使用行情、公司公告、公开报道或研报起草理由。点击「查看依据」核对原文或编辑依据。桌面依次显示模板编辑、草稿预览和套图栏。手机在编辑和预览之间切换，套图栏在预览下方。卡片使用分栏显示股票与参考价、通栏底色显示仓位变化。点击图片文字可修改字段。成品可以复制文案、下载图片或选择多个群发送。

在研究答复的“更多回答操作”中选择“制作服务草稿”。服务草稿保留原答复链接、数据截止日和来源。长答复可选取一段原文，再编辑成 160 字以内的摘录。填入前可核对目标日期和时点。已有判断时会显示“替换今日判断”，替换后可在卡片编辑区撤销。摘录和卡片草稿可在刷新后继续。

样例中的市场数字、买卖安排、仓位和阈值没有作为新卡片的行情或交易结论。晨会、次日内部交易计划、周报和月报不属于此次六个对客时点。

## 编辑与保存

指数先由服务端通过 Tushare、财经行情和 AkShare 获取结构化快照，再交给 Codex 检索财经网站、撰写正文。保留原始记录、来源、数据时点和信息截止时间；三项主要指数涨跌幅不完整时显示采集失败，可选指标缺失时省略。盘前区分上一交易日收盘和隔夜行情，历史盘中卡不能用之后的行情补造原时点。

卡片工作台按“服务时点 → 核心文案 → 成品预览”组织。顶部展示六个时点的采集状态和本机草稿标记，可通过前一天、后一天、今天或日期选择器查看历史卡片。编辑区优先展示服务名称、卡片标题、今日判断、行动安排和观察重点；可展开的“服务落款与风险提示”中保留服务说明编辑，并只读展示固定风险提示及投顾信息。

预览区支持图片和纯文案。下载使用当前排版完成的预览。市场待采集、来源待核实、核心内容未齐或文案未保存时，下载的文件名、图片和复制的文案都会带草稿标记。完整内容保存后可下载成品。手机从“编辑 / 预览”切换，返回时保留编辑位置。市场来源与数据时点可在预览区展开。

“保存本次卡片”保存当前日期、时点的内容；“保存为默认模板”让以后该时点的卡片沿用当前内容。未采集时可先编辑、预览、下载或保存默认模板；采集建立卡片后可保存本次内容。未保存的编辑草稿随当前工作区标签保存在本机当前登录会话中，切换日期或时点后仍可继续编辑。“恢复”回到本次已保存内容（尚无卡片时回到默认模板），可即时撤销。

在侧栏选择「生成计划与模板」，每日生成计划从右侧抽屉展开。支持 Escape 关闭及焦点返回，关闭抽屉保留尚未提交的设置。修改时间、星期或启用状态后点击「保存生成计划」。计划、卡片草稿和默认模板各自保存，计划修改可单独放弃。

在服务日期中选择历史日期可查看、修改和下载已有卡片；“重新采集市场状态”仅重新检索该卡原有的信息截止时点，保留已保存的用户文案，即使后来修改默认计划也不会改变历史卡的截止时间。未来日期或尚未到达的当日时点只可提前编辑模板、预览图片，到对应时刻后才能采集市场事实，避免提前手动采集占用当天的自动时点。09:45 和午间卡都会生成草稿，由用户决定是否使用。

## 每日执行

调度器运行在已有 `llmr-worker` 内，每 20 秒检查一次已启用计划。页面关闭不会停止任务。每日期、时点只有一张卡；定时请求标识固定，重复检查、API 重试和重启恢复均复用同一任务。预留卡片后尚未来得及入队的任务可以恢复入队。

调度只在计划时刻后的 15 分钟窗口内自动触发，停机错过的盘中时点不会事后自动编造行情。已经入队的任务继续遵守冻结的截止时间。默认计划为周一至周五；这不是自动识别法定休市日的交易日历，休市事实由采集结果说明，也可调整生成星期或关闭相应时点。

Codex 使用现有研究队列与原生联网能力；六个固定时点、即时简报和重新采集均显式指定 `gpt-6.1-sol` / `max`，创建会话和任务时冻结该选择，不受普通研究聊天的默认模型影响。模型服务需实际支持该模型，本地账户策略也需匹配已开通权限；未满足模型或推理档位条件时返回清楚的错误，不创建半成品任务，也不自动降级到其他模型。仅视觉复核继续使用普通研究默认模型。

简评采用投资顾问直接面向已签约客户的口吻：先给判断，再写盘面依据，最后说明可验证判断的观察条件。摘要、今日判断、盘面主线和后续关注各自提供新信息，删去“总体来看”“值得注意的是”等过渡套话、重复结论和空泛结尾；证据不足时缩小判断范围，不靠绝对措辞掩盖不确定性。模型输出前自行校读，不将自检过程写进成品。投顾身份和固定风险提示继续由系统统一落款，正文不冒充真人自我介绍。

只传入标准时点任务和冻结日期，不把用户的判断、行动、投顾身份或其他模板文案发送给模型。市场来源必须同时满足实际搜索、实际打开和时点校验；未通过的结果显示采集失败或数据待核实。服务只制作卡片，不向客户群或其他渠道自动发送。

### 简评专用执行流程

`client_service_runtime.py` 只对实际生成卡片的回合启用专用 Codex 基础指令、开发者指令和最小上下文。模型与推理档位继续取任务冻结的 `gpt-6.1-sol` / `max`。普通研究、选股和成品视觉复核保持各自原有流程。

简评直接接收已经校验的行情快照（数值、昨收、实际时点、来源及哈希），完整原始返回值仍保存在服务端。无需复制整个研究资料库、重复传递对话历史、加载通用研究技能或启动 MCP 工具桥；简评关闭终端、子代理、连接器和本地图像工具，保留原生实时网页搜索、打开与页内定位。

查询使用冻结日期、时点和快照中的独特点位定位市场综述，批量搜索和打开原文。已读 URL 不重复打开。可选指标只采用原文明示的口径；必要时追加一批定向核对，仍不能确认则省略可选数值，核心指数不完整仍报错。原文来源、截止时间、指数一致性校验继续由服务端执行。此流程不缓存复用旧行情或将尚未核实的页面摘要作为事实。

模型只返回补充指标和实际引用的网页来源；已有三项指数、行情来源及实际时点由服务端合入成品，减少模型重复抄写数值和时间。模型返回缺失指数时仍走原有来源与时点校验。

可用 `python scripts/profile_client_service.py <card-id> --output <report.json>` 读取某次生成的耗时、工具调用和 token 统计。脚本只读现有记录，不触发生成或改写卡片，也不导出模型思考正文。工具并发等待按区间并集计算，避免将同时执行的抓取和资源查询重复相加；非工具耗时包括模型、排队、初始化和传输，不能直接视为纯推理时间。

2026-11-16 本机实测：原回合 546 秒，其中行情快照约 1 秒、工具等待并集 222 秒（网页归档占 209 秒）、最终正文输出 16 秒；图片渲染另测 189 毫秒。最终精简版 269 秒，工具等待 11 秒，首轮输入由 25,576 降到 8,518 token，累计输入由 343,462 降到 86,016 token，仍为 GPT-6.1 Sol / max。前两次专用流程验证为 257 秒和 249 秒。以上为同日少量实跑，不是延迟保证；网页可读性、任务内容与模型服务负载都会影响耗时。最后一份保留三项原始指数、三个补充指标、五个来源及完整固定落款，数值和实际时点与服务端快照一致。详细本机记录位于 `artifacts/client-service-latency/`。

采集完成和保存内容后，同一图片引擎会生成服务端 PNG，存放在各自工作空间的 `artifact_root/client-service/<card-id>.png`。预览、历史下载和自动生成使用同一渲染器，1080 像素宽，最小高度 1660 像素，图片高度按文字自动增长。七套底图共用财经刊物式排版：插画主视觉与斜切纸面衔接，大标题和服务时刻形成刊头；今日判断采用加粗引言和主题色竖线，行情指标使用三列细线分栏，行动安排使用通栏主题色，观察重点和服务落款以留白、字号与分隔线组织。页尾统一保留风险提示、数据说明与来源。渲染前逐块计算文字换行和高度，长文案、长指标和数据说明不会挤出图片底部。文件通过临时文件加原子替换写入。中文字体使用 Noto Sans CJK，也可由 `LLMR_CLIENT_CARD_FONT` 指定字体路径。

## API

所有接口均沿用本站认证和个人工作区隔离。

| 接口 | 用途 |
| --- | --- |
| `GET /api/v1/client-service/settings` | 读取模板与计划 |
| `PUT /api/v1/client-service/settings` | 按 revision 保存模板与计划 |
| `GET /api/v1/client-service/cards?date=YYYY-MM-DD` | 读取当日各时点卡片 |
| `POST /api/v1/client-service/cards` | 按 request_id 幂等创建或重新采集 |
| `GET /api/v1/client-service/cards/{id}` | 读取采集状态、市场资料和用户内容 |
| `PUT /api/v1/client-service/cards/{id}` | 按 revision 保存用户内容，不接受 market 覆盖 |
| `POST /api/v1/client-service/preview` | 按当前编辑内容返回 PNG 预览，不保存或调用模型 |
| `GET /api/v1/client-service/cards/{id}/image.png` | 下载已保存卡片的图片 |

设置和卡片均有版本检查；发生并发修改时返回 409，用户草稿继续保留。市场采集结果和手工文案分开存储，后台完成不会覆盖手工编辑。专用采集会话不进入普通研究侧栏历史，也不自动生成研究 PDF。

开盘计划通过 `GET /api/v1/client-service/opening-plans/editor/{plan_date}` 读取默认模板和当天已保存的卡片。向同地址发出 `PUT` 保存当天卡片，向 `PUT /api/v1/client-service/opening-plans/template` 保存默认模板，两者独立检查版本。向 `POST /api/v1/client-service/opening-plans/preview` 提交编辑内容可返回图片预览。

## 七套卡片底图

成品预览右侧的纵向套图栏提供“锦绣江岸”“冰蓝科技”“曜金几何”“星穹银紫”“朱砂丹霞”“远洋航线”“铂银建筑”七套原创插画。每套有六个固定服务时点和即时股评的七款不同刊头，合计 49 款；冰蓝科技使用深蓝、冰蓝与银白，搭配晶圆、芯片、光路和数据网络；同套的字体和正文色彩统一，时点场景随盘前、开盘、关键时点、午间、尾盘、收盘、即时股评自动匹配。

点击套图立即更新缩略图、正文配色和成品预览。成品图片左右两侧的“上一套底图”“下一套底图”按钮可在七套风格间循环切换，与右侧选择器同步，保留当前文案。套图选择作为 `content.theme` 随草稿、卡片版本和模板保存：`river`、`jade`、`gold`、`cosmos`、`cinnabar`、`ocean`、`platinum`（`jade` 为兼容已有卡片和草稿而保留的标识，现对应冰蓝科技），旧卡片默认使用 `river`。点击“保存本次卡片”保存本次样式；点击“保存为默认模板”保存当前固定时点的文案和样式；点击“设为全时点默认”只更新六个时点的默认套图，保留所有文案和未提交的计划修改。已生成的历史卡片仍沿用其已保存选择。即时股评生成请求可携带当前 theme，并继续使用即时股评专属刊头。

时点卡片、开盘计划和调仓建议共用七套色系，以及同一组刊头、标题、正文和风险落款排版。七套时点图集位于 `apps/web/public/client-service/themes/`，每张为 2 列、4 行，前七格用于固定时点与即时股评，第八格用于开盘计划。调仓建议在 `apps/web/public/client-service/rebalance-themes/` 中按色系选用自己的插画。时点图集生成提示词在 `output/imagegen/client-service-theme-prompts.txt` 和 `output/imagegen/client-service-technology-prompt.txt`。调仓插画提示词在 `output/imagegen/rebalance-theme-prompts.txt`。预览、PNG 下载、后台自动图片和机器人发送使用同一图片引擎。

## 右侧抽屉与页面缩放

桌面密度样式 `deployment-layout.css` 在宽度大于等于 769 像素时设置 `body { zoom: .8 }`。固定遮罩已经占满物理视口，但其内部抽屉原先设置 `height: 100dvh`，经过 body 缩放后只占物理视口的 80%。共用抽屉样式改为 `height: 100%; max-height: 100%`，直接填满固定遮罩，避免二次缩小；无需改动整个页面的缩放。计划和机器人面板共同使用此修复，内容区内部滚动，页脚按钮保留在底部。

实际验证：桌面 720 像素视口、body zoom 0.8 时，抽屉 top=0、bottom=720，页脚 bottom=720；手机 390×844、body zoom 1 时，抽屉高 844、无横向溢出。

## 实时股评

点击“今日服务时点”中的第一张“实时”卡片，先查看所选日期最新的即时简报；当天没有记录时进入即时简报编辑状态。点击编辑区“生成即时简报”或“生成新一期股评”调用 `POST /api/v1/client-service/briefs`，请求包含 `request_id` 和当前套图 `theme`。仅切换实时卡片不会启动模型。截止时间由服务端取当前北京时间，不受页面日期或六个固定时点影响。Codex 实际检索和打开公开来源，校验信息时点后生成市场快照，以及标题、今日判断、沟通与观察安排、观察重点。休市、延迟与未核实数据需明确标注。

每次点击生成一份独立即时简报，出现在当天“即时简报”记录栏。重复请求标识复用同一任务；页面关闭后由后台继续执行。即时简报不占用固定时点卡，也不能写成固定时点的默认模板。来源、数据时点、用户保存版本和图片下载沿用现有机制。生成完成仅补齐用户尚未修改的字段，保留已保存及本页正在编辑的文案。

## 企业微信机器人

从「服务」侧栏打开「群机器人」，在主工作区切换机器人配置、风险监控、合规审查和内容群发。机器人配置可新增、编辑、启停、移除企业微信群机器人，也可发送连接测试。最近 50 条发送记录可在配置页或侧栏「发送记录」中查看。配置按个人工作区存储，Webhook 密钥保存在服务端数据库，列表和编辑接口仅返回配置提示。编辑时 Webhook 留空可沿用原地址。移除机器人会清除密钥，历史发送记录可继续查阅。

「风险监控」显示发送失败、结果未确认、发送中及已停用机器人。「合规审查」检查外发文案的风险提示、投顾落款、网址、确定性收益表述和格式长度。「内容群发」可勾选多个已启用的群，核对稿件和接收群后确认发送，并查看各群结果。

仅接受企业微信官方 HTTPS Webhook 地址 `https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=...`；发送请求禁止重定向。保存配置不会触发发送。测试消息在机器人管理面板中确认发送。发送简报时，在时点卡片的成品预览点击「发送到群」，选择已启用机器人对应的企业微信群，再确认发送。发送格式与当前预览一致，可发图片或文案。默认没有自动群推送。

发送卡片需已完成采集、保存修改，并通过服务端 revision 检查。文本按 UTF-8 检查 2048 字节上限，超限提示精简或发送图片；图片使用 Base64 与原始字节 MD5，超过 2 MB 时尝试 JPEG 压缩，仍超限则拒绝。限流按机器人每分钟最多 20 次；相同请求标识不重复发送。网络异常或进程中断导致无法确认结果时，显示“结果未确认”，请先查看目标群，服务端不会自动重发。

新增接口：

- `GET/POST /api/v1/client-service/robots`：列表与创建。
- `PUT /api/v1/client-service/robots/{robot_id}`：按 revision 更新。
- `POST /api/v1/client-service/robots/{robot_id}/archive`：移除配置。
- `POST /api/v1/client-service/robots/{robot_id}/send`：发送测试／文案／图片，按 request_id 幂等。
- `GET /api/v1/client-service/robots/deliveries`：最近发送记录。

接口参考：[企业微信消息推送配置说明](https://developer.work.weixin.qq.com/document/path/99110)；[华为云企业微信连接器字段说明](https://support.huaweicloud.com/usermanual-codeartslink/codeartslink_03_0053.html)。


## 面板宽度与紧凑时点卡片

今日服务时点以实时卡片为第一张，随后是六个固定时点卡片。桌面一行七张卡，卡片内边距、字号和间距收紧，最小高度 85 CSS 像素；窄屏自动分行。实时股评顶部独立按钮已移除。未生成的即时卡片可提前准备文案，显式生成后保存到新卡片，避免丢失手工草稿。

工作台保留可滚动布局。编辑区在左，成品预览居中，套图选择在预览右侧纵向排列。面板填满所属工作区宽度。原先 `.workspace-tool-page.page-content` 全局样式设置 max-width=1600px 并居中，优先级高于页面自身选择器，在 80% 桌面缩放下实际仅显示 1280px；页面现在用等优先级的专用规则明确覆盖 max-width 和 margin-inline，同时为内部网格设置 min-width=0，防止窄屏溢出。

模板细节包括时点刊号、标题下装饰线、章节引导线与圆点、细线末端菱形，以及页尾服务标记、日期和刊号。所有装饰随套图主题配色，正文和数据仍独立排版。


## Logo 品牌栏与新增套图

七套底图均已使用 imagegen 修改每格右上角的 Logo 区域：将高亮建筑、光路、星体、反光等移开，以原场景的天空、暗部或材质自然延续。新版文件为 `themes/{theme}-logo-safe.png`。渲染器直接叠加官方透明 Logo，已移除整条纯色品牌栏及其边界线。品牌、标题、时刻继续独立排版。

新增四套为星穹银紫（紫黑与银白星轨）、朱砂丹霞（朱砂与酒红矿物山色）、远洋航线（深蓝海图和银色航迹）、铂银建筑（石墨灰与银白建筑光影）。各套七款时点图与统一正文配色一起接入预览、保存、默认模板、即时简报、下载与机器人发送。


## 全屏预览、同高三栏与套图浏览

成品预览标题栏的“全屏查看”或直接点击成品图片，打开覆盖完整视口的预览。默认按窗口显示整张卡片，点击“放大阅读”可滚动核对细字，再点“适应窗口”返回整图。全屏底部提供上一套、下一套与下载，关闭按钮和 Escape 可退出并把焦点还给原入口。编辑或切换套图后只展示已完成的最新预览，失败时可重试。

桌面编辑区、成品预览、套图选择三栏由编辑内容确定共同高度，顶部与底部对齐；展开编辑区落款后也会同步增高。预览画布和套图列表分别在栏内滚动。窄屏保留上下布局，预览与右侧套图栏同高。

套图栏顶部、底部分别提供“向上浏览套图”“向下浏览套图”。按钮只滚动列表，不改变已选套图或启动模型；到达边界自动禁用。切换当前样式时，列表自动把已选项移入可见范围。未来新增套图会增加列表滚动内容，不会继续撑高整个容器。


## 图片文字原位编辑

普通预览和全屏预览均可点击图片对应的可编辑文字位置直接编辑。悬停显示字段名称，点击后在原位置显示输入框；支持确认、取消、Ctrl/Command+Enter 确认和 Escape 取消。点击编辑框外会提交有效修改。标题、服务名称、今日判断、行动安排、观察重点、服务说明同步到左侧字段；市场摘要与指标名称／数值则作为当前卡片的 `content.market_overrides` 存储。风险提示、投顾姓名、执业编码及机构为固定落款，不提供图片内编辑入口。

原始 `market`、来源、数据时点不被覆盖。市场展示字段可点击“恢复采集文字”移除对应修改，成品及复制文案带手工编辑说明。保存默认模板时清除市场展示修改，避免把某一天的指标带入未来时点。图片编辑使用与 PNG 渲染一致的服务端坐标，预览接口额外返回 `regions` 元数据。重新排版期间保留当前编辑框，下载仍只使用已完成的最新图片。

日期、信息截止时刻和来源归属继续由卡片记录确定，官方 Logo 使用原始品牌资产。

## 指标密度与成品复核

指数数值采用独立紧凑项，保留原始采集文字及来源；预览会检查实际字体换行、指标长度和涨跌方向。来源、数据说明与风险提示已增大字号、加深颜色并放宽行距。已保存的成品可在“成品视觉复核”中提交整图与指标区域图，由 Codex 返回具体视觉问题；编辑后旧结果失效。使用方式、边界与接口见 [内容与成品复核](client-service-quality.md)。


## 结构化取数与客观成稿

后台执行生成任务前先获取指数快照，优先尝试 Tushare 实时、日线或历史分钟接口，再切换到腾讯财经带日期的行情／分时数据和有超时边界的 AkShare 适配器。实时接口未开权限、日线尚未入库、网站暂不可达均自动换源；不会把单一来源的空返回当作已完成。AkShare 日线支持东财、腾讯、新浪路径，分钟数据使用东财；当前部署的网络或供应商限制可导致部分路径暂不可用，诊断保留在工作台，不进入客户图片。

快照保存于当前工作区 client_service_market_snapshots，包含实际接口返回、来源、时间与哈希。在 Codex 开始写作前作为 client_market_snapshot 注入；模型也可以用 read_client_market_snapshot 再次读取，Tushare 凭据继续保留在服务端。数值栏采用实际快照，网页补充指标仍核对实际打开的来源。指数返回与点位／昨收要相符；固定历史时点使用该时刻之前的分时记录，不用之后的报价冒充。即时简报在后台实际取数时更新截止时间，避免队列等待后仍标成请求秒数。

正文使用自然财经中文，描述市场、行业分化和有依据的驱动，不写“已核实快照显示”“尚未核实”“继续补核”“向客户说明”等内部流程话术。即时简报的行动栏改为“盘面主线”，与“观察重点”分工；固定时点仍保留用户行动安排。仅补齐尚未编辑的空白文案，用户文案继续保留。

指数只有涨跌幅而无点位时保留已有涨跌幅。三项指数涨跌幅缺失时不标记 ready；可选成交额、涨停家数等不强行补空格。两市成交总额需要明确口径的原文，不用未经确认的指数成交额相加代替。成品图片页脚只展示简短数据时间、必要口径和来源机构，完整来源标题、链接和采集诊断在来源面板内查看。复制文案采用同样的简短说明。
