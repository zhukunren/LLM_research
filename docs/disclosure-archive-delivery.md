# 原始披露归档交付记录

交付日期：2026-10-20。第二交付包支持手动上传 PDF、导入官方 PDF 链接、公司与报告期分类、修订和补充材料保存，以及物理页阅读与原文检索。公告接口自动采集保持关闭。

## 日常使用

进入“资料库 → 原始披露”，点击“归档原始披露”。上传每份不超过 50 MB 的 PDF，或切换到“官方链接”填写原文下载地址。填写标题、归属公司、报告期末、类型、全文或摘要及披露日期；不确定的字段可以留空，先归档为待核对。

公司页也提供原始披露区，按当前公司和研究截至日期查看。该日期范围只包含已确认分类、且已填写并确认披露日期的版本；其他材料在完整资料库中继续保留。

识别建议来自文件名、前几页文字和已有证券目录，只用于辅助核对。打开原文后点击“核对分类”，可以采用建议并调整。勾选确认后保存；报告期不会被当作披露时间，官方域名也不会自动证明文件的发布日期。

上传或链接请求提交后由后台任务执行。页面可以显示进度、停止导入和重试。链接下载成功但解析失败时，重试复用已下载文件；重新提交链接才重新检查网站上的内容。工作进程中断后也能继续已保存的步骤。

## 原文关系与修改历史

- **新披露**：建立独立资料系列，全文、摘要、审计报告及其他材料分别归档。
- **添加修订全文**：在已确认的原版本上操作，要求公司、报告期、文档类型和全文/摘要形式一致。只能以当前最新版本提交修订，避免同时上传时形成不明确的版本分支。
- **关联更正或补充材料**：建立独立资料系列并关联原版本。更正公告不会覆盖或替代完整年报。

同一文件哈希会复用已有页面索引。已确认分类冲突时，系统要求打开原记录核对，不覆盖既有归属。相同官方 URL 内容改变，且公司、报告期和材料类型都已确认一致时，保存新的修订版本。

每个文件版本保留原始 PDF、SHA-256、导入渠道、URL、时间和前后版本关系，数据库禁止更新或删除版本行。同文件从其他渠道再次导入时，新增来源记录。分类修正以新的元数据版本保存，原来的确认记录仍可回看。

修改多版本系列的公司、报告期或材料类型，需要明确选择同步系列分类；其他版本重新标为待核对。相关补充材料的分类随后若不一致，阅读区提示关联待复核。

## 页级阅读

复用现有 PDF 阅读器，支持翻页、缩放、整页适配和专注阅读。页码统一为 PDF 物理页，包含封面、目录和空白页；不将印刷页码当作索引。

“检索本份原文”返回匹配的物理页和摘录，点击结果即可跳转。单页文字采用有界读取，并提供继续读取入口。图片型 PDF 即使暂无文字索引，也能阅读原文，不能把“未检索到文字”解释为“未披露”。

切换修订版本后，正文、页码和检索结果一起切换。按历史截止日查看时，后来的文件版本不会隐藏更早符合条件的版本，也不能通过该截止日的 PDF 或页接口读取未来版本。

读取原件和页文字前会核对原 PDF 哈希。文件缺失或被替换时显示错误，不拿其他字节冒充原引用。

## 官方链接范围

默认接受巨潮 `cninfo.com.cn`、上交所 `sse.com.cn`、深交所 `szse.cn`、北交所 `bse.cn` 及其子域名。发行人官网可由维护者在配置文件的 `[disclosures] official_hosts` 中登记，使用逗号分隔的完整主机名；额外登记不会自动扩大到所有子域名。

每次重定向在请求前重新验证域名，底层沿用公网地址检查、DNS 地址锁定和 TLS 校验。网页、登录页、非 PDF 内容和超限文件会拒绝归档。

当前代理的双栈 Fake-IP 已完成兼容验证：只有 HTTPS 标准端口上的域名可以通过独立公共 DNS 再核验，实际连接必须锁定到核验后的公网地址。保留地址本身仍不允许连接。

## 实现位置

- `disclosures.py`：分类合同、版本关系、目录、修订发布、元数据历史及页级读取。
- `disclosure_sources.py`：官方域名校验、重定向与有界 PDF 下载。
- `disclosure_sync.py`：下载和解析检查点、后台恢复、取消后的发布保护。
- `disclosure_api.py`：上传、链接、目录、历史、分类修改、PDF、页文本和搜索接口。
- `documents.index_pdf_snapshot`：研报与原始披露共用的文件哈希和页索引逻辑。
- `DisclosuresPanel.tsx`：资料库及公司页入口，复用 `PdfReader.tsx`。

迁移文件为 `042_disclosure_archive.sql`，增加资料类型及披露系列、文件版本、元数据历史、导入任务四张表。原始披露不再混入券商研报目录、研报自动字典或研报研究快照；旧文件 ID 和引用继续可读。

数据沿用当前工作空间数据库和原件目录，现有备份覆盖版本、分类历史及原 PDF。后台任务采用 `disclosure-import-v1` 协议，旧 worker 不会误领任务。

## 验证记录

自动测试覆盖上传、链接、类型与报告期限制、重复文件、跨公司误归档、全文/摘要区分、修订保留、补充材料关系、日期过滤、物理空白页、来源完整性、解析重试、取消后恢复、工作空间隔离、只读角色，以及备份恢复。

真实文件验收使用巨潮公布的[美的集团 2025 年年度报告](https://static.cninfo.com.cn/finalpage/2026-03-31/1225058110.PDF)，共 276 个物理页。官方链接导入后，下载字节与保存哈希一致；再次上传同一文件复用已有版本；第 1、5 和末页的读取已核对，封面和目录已渲染检查。

验收环境与正式资料库隔离，文件位于 `runtime/verification/disclosure-archive-6b87186f00/`。`result.json` 保存后端验证结果，`ui/` 保存网页检查结果及截图；这些生成产物不进入 Git。更正和修订边界使用明确标注的合成 PDF 验证。

后续公告权限开通后，自动采集可将官方链接送入同一归档服务，继续使用现有哈希、分类、版本及恢复机制。
