# LLM 投研工作台

面向研究员、投顾和需要复核研究材料的同事。启用技能后，可以在开阳同智里继续已有研究项目，查行情、资讯和研报，核对财报数字的报告期、口径和原页。也可以试算选股条件、运行已保存的方案、解释历史批次的入选依据，或整理情报简报、对客草稿和 QMT 脚本。任务编号、版本和证据随结果保留，成果可通过链接打开或下载。

在开阳同智导入已授权的工作台 Skill ZIP。在对话中输入 `/`，选择 `llm-research-workbench-workspace` 并发送。网页和聊天操作面板会一起打开，左侧可切换研究、选股、观察池、情报、资料、信号和服务。[投研工作台网页](https://zjg.dwzq.top/)
