# 观察池第一版 · 2026-09-29

“我的自选”页面已替换为“观察池”，包含“选股”和“观察池”两个 Tab。原人工自选名单不迁入新观察池；新观察池以真实选股运行批次为单位。

## 使用流程

1. 在“帮我选股”核对条件并保存方案。
2. 在“观察池 → 选股”选择保存方案的版本、行情截止日和范围，核对条件后执行。加载方案不会运行计算，也不会再次调用模型生成条件。
3. 每次执行保留实际时间、行情截止日、有效信号日、完整条件及参数、冻结的证券范围、入选参考价和全部证券判断。网络重试使用同一请求标识，重复请求复用原批次；新的主动执行生成新批次。
4. 执行完成后点击“查看本批次观察”，或在观察池选择历史批次。历史检索覆盖新体系的对话选股记录和直接执行的保存方案，不限定原对话。
5. 列表选择股票即可切换 K 线。观察页默认延伸到最新行情，也可切回当时视角。保留信号前 60 根及其后全部日线，不受原 500 根限制；入选标记按批次保存，同日多次入选聚合标记、展开记录分别展示。
6. 每只入选股票可记录备注，标为观察中、重点关注或结束观察。结束观察不会删除历史，也不会从整个批次的统计中排除。
7. “导出结果字典”下载 JSON，包含条件快照、执行起止时间、汇总以及以证券代码为键的全部判断（含未入选和数据不足）。

## 统计口径

- 信号日取本次执行冻结的有效行情日，与实际执行时间分开。直接执行早于当时行情水位的日期时标识“历史补算”。
- 涨跌幅以当前同一复权序列中的信号日收盘价计算，避免前复权基准变更后直接混用旧快照数值。执行时的参考价格独立保留，不被刷新覆盖。
- 支持入选至最新、5／10／20 个交易日的平均涨跌幅、中位数、上涨占比和有效样本数。个股提供对应周期涨跌幅、期间最高／最低相对涨幅和有效行情天数。
- 周期以本地全市场有行情的交易日期为序列；个股停牌或缺少目标日行情时留空，不能用下一根行情替代。当前尚无独立的交易所历史日历，若全市场某个交易日全部缺数，需要先补齐数据。
- 未满期、缺少信号日行情、目标日期无有效行情不计入对应周期样本。最新价格过期时展示其真实行情日期，不计入最新周期统计。异常 K 线留空；期间存在异常行情时不提供区间最高／最低涨幅。
- **现有行情服务仍将复权口径返回为 unknown。第一版不会据此给出可比涨跌幅，页面显示原因，价格、观察天数、标记和备注正常可用。** 后续需要在行情来源层接入并验证复权元数据或复权因子，不能通过改页面开关伪装为已确认。受控测试用确认过口径的合成数据验证统计计算。
- 旧对话批次未保存入选参考价时，明确显示“旧记录未保存参考价”，不回填为原始快照。旧版组合策略与其运行历史仍可在“帮我选股 → 高级组合／筛选记录”使用，不混写到新的保存方案表中。
