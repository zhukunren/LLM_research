# 研究与服务导航

侧栏一级入口为“研究 / 服务”。研究侧栏提供新建任务、搜索与跳转、观察池、资料库、每日信号汇总、研究工具和最近任务。研究工具包含 QMT 脚本生成和形态库。底部是“数据与连接”。

侧栏“新建任务”按当前任务类型创建草稿。“研究对话”和“选股对话”的切换按钮只在新建任务页显示。切换时可找回对应类型的未发送草稿。已有对话可从工作区标签、最近任务或搜索打开。旧项目链接会打开新建任务页。最近任务用标签标明研究或选股，打开时在相应行显示进度，失败时可点击同一行重试。

从「选股对话」发起自然语言筛选。「选股工具」提供固定规则试算、形态样本编辑、组合选股、条件库、管理方案和筛选记录。空白对话可用「组合多个条件」直接进入编辑器，也可在输入区引用已有方案。

点击输入区“引用方案”浏览对话方案和条件组合，选定版本后在输入框显示可移除的 `@方案名称 · v版本`。可补充要求，也可直接选择“只生成方案”或“执行选股”。在输入框按 Enter 执行所显示的主要动作。

提交时服务端校验引用的方案版本，并保存该版本完整快照及哈希。条件组合同时保存其引用的条件和形态版本；历史消息不随库内后续编辑变化。不存在或不完整的版本引用拒绝提交，原输入与引用保留供重试。后续选股处理使用该快照和当前要求，通过原有执行授权流程生成及执行任务。研究输入区继续提供“我的指标”。

「固定规则与试算」在选股对话中打开。试算后可将规则加入当前要求，或按所选范围和截止日独立筛选。方案的「资料条件」统一管理资讯和研报条件，可逐条设置来源、发布窗口及研报的证据口径。添加后先进入待发送要求。

「选取形态样本」打开形态编辑器。选用已保存版本或保存当前修改后，可带回发起的选股对话，或加入发起的组合。另一种去向会恢复最近的对应工作区。点击原先的工作区标签可回到对话草稿。技术、资讯和研报的历史地址可继续打开对应的旧草稿。

研究答复可转为带来源的选股草稿，候选结果可继续研究；转换会打开独立工作区。研究转服务草稿也保留原研究和时点，具体行为见 [对客服务](client-service.md)。已打开工作区继续支持多任务标签、排序及恢复；单个工作区采用简化标签外观。

从研究输入区打开「读懂一份研报」或「选研报」时，研报页会带上原问题。「用此页继续研究」将当前原页加入发起的草稿，可继续选择别页。「带此页去选股」把原问题和已选原页带入独立选股草稿。两个入口的「只生成方案」和 Enter 都先整理条件。选择「生成并筛选」才直接提交筛选。搜索范围以外的研报可以继续读，清除搜索并明确选用后才能把它带回草稿。

沿用原有研究、选股、方案、记录及资料库 URL 与存储，未合并后端 workflow_type，也不改写已有对话所属类型。通过旧链接进入时读取服务端对话类型，打开对应研究分区。选股结果的桌面分栏、手机抽屉和批次快照行为见 [选股结果工作区](research-results-workspace.md)。
