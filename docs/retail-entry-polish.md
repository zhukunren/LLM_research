# 散户首次使用体验打磨

本轮聚焦“帮我选股”的首次使用流程和全局导航，保留现有资料库、选股、保存方案与观察池的数据协议。

- 导航将“帮我选股”放在首位，随后是观察池；放大导航、对话列表和主要操作文字。
- 新建对话时隐藏尚无内容的条件与结果栏；出现消息、条件或运行结果后显示核对区。
- 示例卡片直接展示实际要求，点击只填入草稿并聚焦输入框，不发送、不创建对话、不执行筛选。
- 原“超跌反弹”示例更换为“近期回调”，使用明确的涨跌幅和均线条件，避免标题暗示未经验证的反弹。
- 新增可展开的一分钟指引，解释描述需求、核对筛选、保存与观察，以及数据不足的含义。
- 默认范围和日期以摘要展示，展开后可修改；继续保留对话草稿及任务核对流程。
- 小屏幕默认收起最近对话和已保存方案；首次输入框放在示例前方，减少到达输入区的滚动。
- 调整卡片留白、圆角、边框、主次文字对比度，支持减少动态效果的系统偏好。

验证：生产构建通过；9 个前端测试文件、32 项测试通过。新增测试覆盖首次页面隐藏空结果栏、示例填入与聚焦、不提交写请求。浏览器检查 1440px 桌面和 390px 手机布局、历史入口展开及键盘选用示例；手机页面未出现横向溢出。此轮未重新调用模型或执行真实选股，筛选行为通过已有前端测试回归。构建仍提示观察池依赖包超过 500 kB，后续可针对图表依赖继续优化加载。
