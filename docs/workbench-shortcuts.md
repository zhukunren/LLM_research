# 研究对话快捷命令

在研究对话的输入框输入 `/`，选择命令，再输入公司名称或股票代码。支持当前证券目录内的 A 股公司，指数不参与公司匹配。命令查询使用本地目录，输入时不逐次请求 Tushare。

- `/财务 贵州茅台`：打开该公司的标准财务面板，可切换年度、累计、单季、TTM、历史截止日和数据版本口径。
- `/披露 000333`：打开美的集团的原始披露归档，查看报告期、原始 PDF 和修订版本。
- `/公司 600519.SH`：将当前公司切换为贵州茅台，在输入框旁显示名称和代码，后续提问会明确附上当前公司。
- `/研报 五粮液`：按登记证券代码查看该公司的本地研报，支持标题筛选、分页及 PDF 原文阅读，公司归属待核对时保留提示。
- `/资讯 601126`：查看已关联四方股份的本地资讯，支持关键词检索、分页及保存版本正文阅读。
- `/行情 600519.SH`：查看贵州茅台本地日线，可设置截止日；显示实际数据日期、记录数量与单位/复权口径状态。

长名称 `/查财务`、`/打开原始披露`、`/切换公司` 同样可用。公司支持中文全名或部分名称、六位代码和完整代码，完整代码的市场后缀不区分大小写。也接受 `SH600519` 形式；六位代码从目录匹配，不自行猜测交易所。结果始终同时显示公司名称与完整代码。

## 输入提示与键盘

输入 `/` 展示六条命令；输入公司参数后展示最多八个匹配结果，精确匹配优先。用 ↑ ↓ 移动选择、Enter 确认、Tab 补全、Esc 关闭提示，也可以鼠标点击。选择公司时 Tab 只补全完整代码，Enter 才执行。中文输入法组词过程中的回车不会执行命令。

没有当前公司时，资料与行情命令会提示输入公司；已有当前公司时可直接输入 `/财务`、`/披露`、`/研报`、`/资讯` 或 `/行情`，确认使用它。`/公司` 后也可以继续输入其他公司。未知命令、未匹配的公司、空参数和多行命令会显示提示，保持草稿供修改。

命令与普通研究消息分别处理：命令直接完成本地选择或打开现有面板，不创建研究对话或发送模型消息。模型不可用时仍可读取这些面板。财务使用已入库数据，尚未采集的公司或期间显示缺口；披露使用已归档文件。执行命令不会自动开始财务同步或公告采集。

研报按已登记的证券代码精确匹配，不把仅在标题提及公司的行业研报自动归入该公司。尚未确认归属的候选记录可以阅读，但明确显示待核对；未绑定的研报仍在资料库。资讯使用已有公司的关联筛选，检索和翻页保留公司参数；缺少关联记录时显示空状态。行情使用本地日线和现有图表，切换截止日立即隐藏旧图再读取，不将本地最近数据称为实时行情。三个新入口仅发出读取请求，不启动研报自动字典整理或资讯导入。

## 当前公司与草稿

当前公司卡片提供“查财务”“原始披露”和“清除当前公司”。从卡片打开面板保留正在编辑的普通问题和附件；关闭面板回到输入框。打开其他公司的财务、披露、研报、资讯或行情，不会修改当前研究公司。

发送新问题时，当前公司以“当前研究公司：名称（完整代码）。”明确写入消息，随后才是用户的问题；不会隐式修改后台研究范围、截止日或股票池。原有对话历史保持原文，重新处理旧的失败问题仍使用原问题中的公司。当前公司与失败消息重试信息一同随新对话创建迁移，避免重试时换成其他公司或重复添加公司前缀。

选择按用户、工作页和对话隔离，保存在当前浏览器会话中；刷新同一草稿可以恢复，开始新研究会清除新草稿的公司。清除当前公司保留正在编辑的问题。

## 实现与验证

前端命令解析与公司匹配位于 `companyCommands.ts`，交互与公司状态位于 `useCompanyCommands.tsx`，提示列表和阅读面板分别为 `CompanyCommandMenu.tsx`、`CompanyCommandDialog.tsx`。财务与原始披露继续复用既有组件、接口和权限判断，没有新增后端数据迁移。

新增 `CompanyReportsPanel.tsx`、`CompanyNewsPanel.tsx`、`CompanyMarketPanel.tsx`，复用现有 `/documents`、`/news`、`/news/{id}`、`/securities/{code}/bars` 读取接口、PDF 阅读器和行情图表。相关测试覆盖公司归属精确筛选、PDF 切换回到首页、资讯搜索/翻页公司参数、正文归属变化、行情历史截止日、缺失及读取失败。

测试覆盖名称及代码、同号代码与指数区分、键盘补全、鼠标选择、中文输入法、未知及多行命令、目录失败重试、模型不可用、草稿保存、公司上下文、消息失败重试，以及旧问题重新处理。面板内部表单与研究消息提交分开，避免资料操作发送输入框中的草稿。

相关测试和生产构建通过。真实浏览器已验证名称/代码打开、当前公司、草稿保留、关闭后输入焦点、中文输入法，以及 390 像素窄屏；未发现脚本错误或页面横向溢出，验证全程没有写请求或模型消息。记录与截图位于 `runtime/verification/company-commands-20261020/`，可用 `scripts/verify_company_commands_ui.py` 对已运行的工作台复现。

六命令扩展的 18 项相关测试通过。真实浏览器读取了资料库登记的五粮液 PDF、四方股份资讯正文和贵州茅台日线，验证了截止日查询、当前公司保留和移动视口；记录位于 `runtime/verification/company-commands-extended-20261020/ui-result.json`，同目录保留截图。新增入口沿用现有读取 API，本地服务无需数据库迁移或后台重启，刷新页面即可使用。

现有资料库把上述五粮液 2024 年年报登记在研报分类中；快捷入口沿用既有分类，本次未改写历史记录。该样本用于验证 PDF 阅读，不作为券商研报内容分类正确性的证明，历史分类需另行核对。
