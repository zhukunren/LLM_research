# QMT 内置 Python 资料库

资料位于 [应用资料包](../../apps/api/app/assets/qmt/catalog.json)，由脚本生成工具直接读取，安装包也包含这些文件。

- **官方接口参考**：依据迅投官方文档整理的本地事实参考页，保留原文链接、核对日期和内容哈希；不是官网完整镜像。覆盖生命周期、上下文、行情、委托、枚举、回调、对象字段与运行准备。
- **项目编写手册**：[策略编写手册](../../apps/api/app/assets/qmt/manuals/strategy-handbook.md)。这是项目约定，区别于官方 API 定义。
- **项目源码示例**：[均线信号](../../apps/api/app/assets/qmt/examples/ma_signal.py)、[放量突破](../../apps/api/app/assets/qmt/examples/volume_breakout.py)、[仅回测均线](../../apps/api/app/assets/qmt/examples/backtest_ma.py)。源码为项目编写，未在用户券商 QMT 上验证。
- **官方完整示例原文**：[迅投完整示例](https://dict.thinktrader.net/innerApi/code_examples.html)。原始完整说明由官方提供。

## 生成工具如何使用

助手先通过 `search_qmt_docs` 找接口，再通过 `read_qmt_doc` 阅读正文，可按偏移分页。查询结果区分 official_reference / manual / example，返回适用环境、来源、版本、内容哈希和未验证项。库在本地离线可用，不依赖向量数据库或实时联网。

QMT 助手第 2 版及以后在导出前检查本轮已完成的真实正文读取。尚未查阅手册、生命周期或源码涉及的常用接口时，导出返回缺少条目，助手补读后以新工具调用重试。搜索摘要、上轮读取、部分分页和模型自行声称“已查阅”不满足检查。此检查是资料查阅记录，不证明模型理解正确或所有接口已经覆盖。

导出返回实际阅读依据及资料包版本/哈希，保存在对话工具记录中，回答需展示使用依据。旧对话沿用冻结的助手版本；新能力请从 QMT 工具重新发起，或在空闲对话中重新选择 QMT 助手，历史轮次不改写。
