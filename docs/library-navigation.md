# 以资料库为入口的条件工作流

## 2026-09-29 阅读界面更新

- 资讯浏览以列表和正文为主，默认正文 14px，A+ / A- 在 12–24px 间调整并保留设置。右上角“导入”接收网址，由独立无头浏览器读取页面，模型整理后存入本地。描述需求按北京时间日期区间先查询资讯，再分批进行模型匹配并核对引用；最近描述可点击恢复文字和日期。日期匹配结果保存在草稿历史中，旧版关键词条件 API 仍保留。
- 技术指标默认使用 `000001.SH`，选择指标、修改周期或截止日后自动刷新。主图与副图共享日期索引，十字光标显示日期、OHLC 和所有指标线数值。上证指数放在独立缓存，优先使用配置的 Tushare 中转，接口不可用时使用腾讯指数行情，不加入股票筛选范围。
- 形态浏览展示全体本地证券最近 120 个结束窗口中原始相似度最高的真实蜡烛图，标注证券与日期；不应用近期窗口的时间衰减。“描述需求”中统一提供文字、绘图、截图和直接匹配，取消指定证券的行情对照。“我的形态”默认真实 K 线，可切回原始曲线。
- 研报上传、索引后自动排队建立字典，已有研报在阅读页面自动补齐。模型读取 PDF 的各页，提取代码、股票名称、标题、分析师、券商、主题、主要观点和发布日期，并核验原文引用。字典小字显示，不再要求用户确认文件名候选。无法核验的信息不自动确认，可重新整理。阅读器直接使用 PDF.js 渲染 PDF 原件，支持翻页、缩放和浏览器打开，不以提取文字替代 PDF。
- 资讯、技术、研报的描述页已移除引导说明和示例按钮，保留输入、结果及可点击的最近描述。

以下内容为此前工作流及验收记录；涉及旧的资讯入口和人工确认步骤，以本节为准。

2026-09-27，根据用户补充的使用方式调整：用户既要看资讯、指标、形态、研报，也要在阅读和观察过程中描述筛选要求。因此以资料类型作为一级导航，将条件创建放在资料所在的位置。

## 导航与职责

| 一级菜单 | 浏览内容 | 条件创建与复用 |
| --- | --- | --- |
| 观察池 | 股票名单、备注、个股行情 | 管理被筛选的名单，收集筛选结果 |
| 资讯库 | 资讯阅读入口和数据连接状态 | 描述关注内容、保存资讯条件，明确数据依赖 |
| 技术指标库 | 指标说明、真实数值与历史走势 | 从所看指标带入描述，生成、试算、保存条件 |
| 形态库 | 已有形态、手绘、截图和目标曲线 | 文字生成形态草稿，检查或修改后保存并加入组合 |
| 研报库 | 原文检索与逐页阅读 | 从当前页整理条件，保存报告、页码和文件哈希来源；按条件评估证据 |
| 组合选股 | 跨库组合和筛选记录 | 引用固定版本，执行全部满足、任一满足、排除、嵌套及股票池筛选 |

资讯、技术和研报库采用“浏览内容 / 描述需求 / 我的条件”；研报增加“证据评估”。形态库采用“浏览形态 / 描述需求 / 我的形态”。页面内部用一致的操作语言，内容展示按资料类型设计。

## 条件引擎保持统一

四个库共用已有版本、来源、组合树和运行记录机制。前端按库保存输入、草稿和确认修改，避免切换资料库时覆盖另一库的内容。旧版未分类但只含一种条件的草稿可以在对应库查看并继续修改；已有条件、形态和运行保留。

新草稿请求可携带 `library`。模型按该库语境生成；如果输出属于另一种库，会提示分别创建后组合，不会错误归类。研报库中不必每句话重复“研报”，当前页面已表明证据来源。

阅读页可传入报告 ID 与页码，服务端核验后保存标题、页码与 SHA-256。该字段记录条件的阅读来源，不等于该报告已经满足条件，也不自动确认报告可用日期或证券归属。

条件编译器版本更新为 `condition-plan-v2`。针对真实模型样例发现的“实际增长或未来预测”歧义，增加证据约束提示与独立检查：用户要求实际业绩时，未来预测不能作为替代命中条件；没有实际数据时保留数据不足。首次验收中由本任务生成且未被引用的歧义条件已退回草稿，其完整快照保留在 `reject_qa_semantic_mismatch` 审计事件中。

## 形态描述

新增 `/patterns/draft` 与 `pattern_drafts` 表。当前支持 V 形反转、双底、圆弧底、上涨后回调四类可检查模板，周期为 10–250 个有行情交易日，相似度为 0–100 分。明确格式可本地解析，自由描述使用已配置模型选取受支持结构。

模型选择结构，程序生成目标曲线，用户查看曲线和参数后确认保存。不能表达的量价幅度、颈线突破、保证收益等要求保留问题，不替换成近似规则。保存的模板保留原话、草稿、模型、算法版本和初始点列；最终点列和参数随形态版本保存。组合执行与结果详情包含实际相似度、要求分数及来源。

## 当前数据边界

- 资讯源仍未接入，浏览页明确显示无已接入记录。可以保存明确的原文关键词定义，但运行时仍为数据不足；未实现的事件语义和金额抽取不会伪装成关键词判断。
- 日线仍按本地示例数据探索，复权等金融口径需要后续核实。
- 研报代码、首次可用日期仍需核验。新评估页提供按固定条件版本、截止日执行及页码证据查看。
- 形态相似度是已有归一化距离算法的分数，不代表交易收益或识别准确率保证。
