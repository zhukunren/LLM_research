# 对客卡片内容与成品复核

市场采集要求主要指数各自独立成项，指标栏只展示名称、点位、带方向的涨跌幅、单位和实际数据时刻。定性分析写入摘要，数据延迟和统计口径写入说明。服务端使用有版本的紧凑格式，解析时保留原始 `raw_metrics`、来源地址和时间；未知价格、缺少方向的百分比不能由相邻指标补齐。历史手工展示字段保留原有顺序，避免编辑覆盖项错位。

预览、下载及视觉复核共用同一服务端 PNG 渲染器。预览返回图片 SHA-256 和指标长度检查；手工输入的长指标会显示提醒，编辑功能继续保留。来源面板展示完整原始采集文字。

成品预览下方“成品视觉复核”可手动提交已保存且采集完成的卡片。后端建立独立的隐藏任务，将完整 PNG 和指标区域 PNG 作为原生图片附件交给已配置 Codex 运行时；审阅不重新采集行情、不自动修改业务文案。结果包含通过／需调整、摘要和逐项建议，并绑定卡片版本与图片哈希；图片变化后，旧结果不再显示为当前图片通过。草稿或未保存内容不能开始复核。

接口为 `POST /api/v1/client-service/cards/{card_id}/review`（request_id 与 expected_revision）及同路径 GET。请求可幂等重放，后台 worker 恢复未完成的排队任务；异常输出或图像输入失败标记为失败，不伪造通过结果。结果保存在所属用户工作区的 `client_service_reviews`。

视觉复核只作为排版与信息组织的辅助检查。即使返回通过，行情数字、正负号、单位与来源仍需通过结构规则和原始资料核对。

生成前的指数快照已独立于模型取数：后台先尝试 Tushare、财经报价与分时数据、AkShare，再把实际点位、涨跌幅、时间、原始响应和来源交给 Codex 成稿。写作允许财经网站并要求客观叙述；内部采集失败说明留在来源面板，图片只保留简短时间、必要口径和来源机构。三项主要指数缺少涨跌幅时不标记成品；只拿到涨跌幅时保留已有信息，不因缺少点位而整体显示未知。
