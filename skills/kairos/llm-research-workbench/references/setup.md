# 在开阳同智连接服务器

项目和数据由服务器上的投研工作台管理。员工在开阳同智使用个人 MCP 连接配置即可访问已获准的业务资料。

在「设置 → 技能」导入已授权的工作台 ZIP。发送「打开投研工作台」并点击回复中的链接，就能在开阳打开网页。发送「打开操作面板」可在聊天消息里进入带侧栏的面板。

## 单独安装 Skill 和连接器

1. 从 ZIP 安装 `llm-research-workbench.zip`，在要使用的智能体中启用「LLM 投研工作台」。
2. 进入「设置 → 连接器 → 添加 → 从 JSON 导入」，导入维护者单独发放的个人连接配置。包内的 `assets/mcp-remote.json` 记录接入地址 `https://zjg.dwzq.top/mcp` 和 Streamable HTTP 类型。个人配置还包含登录用的请求头，请保存在连接设置中。
3. 在该智能体中启用 `llm-research-workbench-remote`，新建对话并发送「在对话里列出研究项目和已保存方案」。工作台会在对话里返回服务器中的条目。

后续可以说「读取这个项目最新的研报」「用上次保存的规则试算这一只股票」或「根据当日资讯起草收评，给我核对引用」。

## 授权问题

- **对话提示工具未连接或 MCP 返回 `401`**。使用预置连接的 Skill 时请维护者更新 ZIP。单独安装 Skill 时，在开阳同智检查个人连接配置和 `llm-research-workbench-remote` 的启用状态。
- **网页登录**。首次访问时，在网页表单输入原账号和密码。[投研工作台网页](https://zjg.dwzq.top/)

远程文件上传使用客户端提供的文件名和内容。附件超过工具的请求限额时，在对应的研究对话网页上传后，再让智能体按会话编号读取。
