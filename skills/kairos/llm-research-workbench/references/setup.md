# 在开阳同智连接服务器

项目和数据由服务器上的投研工作台管理。员工在开阳同智使用个人 MCP 连接配置即可访问已获准的业务资料。

1. 在开阳同智的技能管理中导入 `llm-research-workbench.zip`，在要使用的智能体中启用「LLM 投研工作台」。
2. 进入「设置 → MCP 服务器 → 添加 → 从 JSON 导入」，导入维护者单独发放的个人连接配置。包内的 `assets/mcp-remote.json` 记录接入地址 `https://zjg.dwzq.top/mcp` 和 Streamable HTTP 类型。个人配置还包含登录用的请求头，请保存在连接设置中。
3. 在该智能体中启用 `llm-research-workbench-remote`，新建对话并发送「打开完整投研工作台，列出我的研究项目、已保存的选股方案和观察池」。工作台返回服务器中的条目。

后续可以说「读取这个项目最新的研报」「用上次保存的规则试算这一只股票」或「根据当日资讯起草收评，给我核对引用」。查看或下载结果时，可在网页里打开工具返回的链接。[投研工作台](https://zjg.dwzq.top/)

远程文件上传使用客户端提供的文件名和内容。附件超过工具的请求限额时，在对应的研究对话网页上传后，再让智能体按会话编号读取。
